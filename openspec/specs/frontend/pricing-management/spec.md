# frontend/pricing-management Specification

## Purpose

提供模型定价管理页面，集中展示内置、自定义文件和覆盖定价的来源与版本历史。登录用户可查看定价。管理员可追加输入及输出单价，使用零价记录已知免费的用量。

## Requirements

### Requirement: 定价管理

登录用户 SHALL 能查看三源合并的模型定价目录（内置/自定义文件/覆盖标注）、按模型查看版本历史。只有管理员 SHALL 能以追加方式提交自定义定价（最新覆盖生效，无编辑删除）。前端 SHALL 仅向已确认的管理员展示追加表单，API SHALL 对普通用户的追加请求返回 403。表单和 API SHALL 分别接受有限非负的输入与输出单价。表单 SHALL 提示 `0` 表示该项免费，并拒绝空白、负数和非有限值。

#### Scenario: 目录与来源标注

- **WHEN** 用户打开定价页
- **THEN** 目录列出各模型价格并标注来源类型，覆盖项可辨识

#### Scenario: 追加自定义定价

- **WHEN** 管理员为某模型提交新价格
- **THEN** 目录与该模型历史随之更新，追加式覆盖语义在界面说明

#### Scenario: 保存和回读零价

- **WHEN** 管理员追加输入或输出单价为 `0` 的价格版本
- **THEN** 该版本保存成功，定价目录和历史显示相应的零价

#### Scenario: 普通用户读取定价

- **WHEN** 普通用户打开定价页或查询定价目录和历史
- **THEN** 目录和历史可读，追加表单不可见，直接调用追加 API 返回 403，定价历史保持原样
