## Context

个人题库在文件元数据数据库中按所有者保存。评估执行已有题目快照机制，可继续保留历史元数据。

## Decisions

- 预览复用 TagManager、DifficultyCalibrator 和评估结果的所有者校验及有效执行口径。每个策略的有效执行计为一个样本，零样本保留难度。
- 保存请求携带预览参数、预览校验值及逐题批准项。服务端重新计算预览，验证批准项，并在写事务内检查源题库版本。新版本保存选定题目的完整快照，包括选中但没有批准变更的题目。
- 版本与原题目共用 ID，通过题集版本 ID 选择数据。评估记录在文件数据库的运行登记中关联版本，worker 从对应版本冻结题目快照。
- 题库页面提供题目勾选、逐项审核、版本列表与详情。复用评估创建页面和题目选择流程。
