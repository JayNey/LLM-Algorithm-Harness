## Why

`AlgorithmHarness` 当前会把 `HarnessConfig.model_dump()` 直接写入日志，导致配置文件中的 API Key 以原文出现。模型调用异常、结果快照和报告导出也可能继续传播包含凭证的文本。

## What Changes

- 将 API Key 作为秘密值保存，普通配置序列化、字符串表示和日志中只展示脱敏占位符。
- 提供统一的递归脱敏工具，覆盖嵌套映射、序列、异常文本、结构化日志和结果导出。
- 在模型客户端边界解析直接密钥、默认环境变量和显式环境变量引用，只有 SDK 初始化能获得原始值。
- 清理模型客户端错误，避免供应商异常把请求凭证传播到日志或结果。
- 增加假密钥回归测试并更新配置文档。

## Capabilities

### New Capabilities

- `secret-redaction`: 定义配置秘密值的解析边界，以及日志、异常和导出内容的统一脱敏行为。

## Impact

- 影响配置模型、模型客户端、结构化日志、JSON 结果和报告导出。
- 不引入外部密钥管理服务，不改变供应商请求协议。
