## Context

题目列表沿用固定的 evaluation-options 元数据契约；个人集合按账号存储，文件导入在事务内按 problem_id 去重。LeetCode 导入器已支持单题获取和 Problem 转换。

## Decisions

- 新增认证的 `POST /api/v1/problems/import/leetcode` 和 `GET /api/v1/problems/personal/{problem_id}`。追加导入仅接受单题链接；现有文件入口和列表结构保持兼容。
- Web 边界限定国际站 HTTP(S) 域名及单题路径，允许常用的 description 子路径并归一化。导入器只访问固定 GraphQL 端点，拒绝跳转，限制超时和请求频率，区分不可访问、限流与超时。
- 复用个人题库事务的合并与容量限制，避免创建临时上传或后台作业。重复题目保留现有数据；所有外部查询和转换成功后才开始写入。
- 在当前导入面板添加独立链接输入，复用文件导入的提交锁、会话隔离和列表刷新；个人题目抽屉独立读取安全的详情字段。使用现有组件和国际化资源。

## Risks / Trade-offs

- 外站不可用时同步请求会失败；限时查询并提示重试，题库保持原样。
- 外站样例或 Python 签名不可靠时，保留导入器的人工补全标志；题面和来源可继续浏览。
