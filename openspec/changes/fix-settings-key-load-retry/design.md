## 实现

- 资料读取沿用表单初始化流程。每次读取创建独立的取消信号，失败或无资料时提供只重新读取资料的按钮。资料更新响应写入会话前核对请求生命周期和会话标识。
- 密钥管理和基准运行表单复用可取消的读取状态。挂载、手动重试和写入后刷新各触发一次读取周期。加载、错误、成功空列表和成功有数据分别渲染。
- 密钥管理页将操作通知与列表状态分开。成功时先确认操作，添加后立即清空表单，再发起读取。重试仅发出 GET。读取未确认时隐藏依赖列表的操作。
- 沿用现有会话标识、页面生命周期和 HTTP 请求的会话校验。删除确认框随所属列表项卸载，避免旧会话的确认回调触发新请求。
- 基准密钥读取失败时只重试密钥列表。列表未成功提供可用密钥时禁用选择器和运行按钮。
