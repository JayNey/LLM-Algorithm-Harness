## Purpose

为本地用户提供一致、可安装且可验证的命令行入口，并确保配置文件、显式参数和默认值按照明确优先级共同生成一次有效评测配置。

## ADDED Requirements

### Requirement: 可安装入口与模块入口行为一致
系统 SHALL 提供可安装的 `harness` 命令，并使其与 `python -m src.main` 调用同一个命令行实现。

#### Scenario: 查看安装命令帮助
- **WHEN** 用户在已安装项目的环境中运行 `harness --help`
- **THEN** 命令以成功状态退出并展示可用参数

#### Scenario: 查看模块命令帮助
- **WHEN** 用户运行 `python -m src.main --help`
- **THEN** 命令以成功状态退出并展示与安装命令一致的参数

### Requirement: 配置来源采用确定的优先级
系统 SHALL 同时支持 JSON 和 YAML 配置文件，并按“显式 CLI 参数 > 配置文件 > 程序默认值”的顺序解析数据集、输出目录和题目筛选条件。环境变量仅用于模型客户端约定的密钥来源。

#### Scenario: 仅使用配置文件
- **WHEN** 配置文件包含数据集与输出目录且用户未传入对应 CLI 参数
- **THEN** 评测使用配置文件中的数据集与输出目录

#### Scenario: 显式参数覆盖配置文件
- **WHEN** 用户同时在配置文件和 CLI 中指定数据集、输出目录或筛选条件
- **THEN** 只有明确传入的 CLI 值覆盖对应配置值

#### Scenario: 命令行补足配置文件缺少的数据集
- **WHEN** 配置文件未包含数据集路径但用户显式传入 `--dataset`
- **THEN** 系统在校验运行配置前使用命令行数据集路径

#### Scenario: 加载 YAML 配置
- **WHEN** 用户通过 `--config` 指定合法的 `.yaml` 或 `.yml` 文件
- **THEN** 系统按与 JSON 相同的数据模型加载配置

### Requirement: 无效运行配置必须在评测前失败
系统 MUST 在调用模型前拒绝缺失数据集、非正问题数量、未知策略、无策略以及筛选后无题目的配置，并返回可理解的错误信息和非零退出状态。

#### Scenario: 无数据集来源
- **WHEN** 用户既未传入 `--dataset` 也未在配置文件提供数据集
- **THEN** CLI 拒绝启动并说明数据集是必需的

#### Scenario: 非正问题数量
- **WHEN** 用户传入零或负数作为 `--limit`
- **THEN** CLI 在评测开始前拒绝该参数

#### Scenario: 策略选择为空
- **WHEN** 配置中没有策略，或显式选择的策略不在有效配置中
- **THEN** CLI 在评测开始前失败且不会写出成功结果

#### Scenario: 筛选无匹配题目
- **WHEN** 难度或标签筛选后没有任何题目
- **THEN** Harness 失败并说明筛选结果为空

### Requirement: CLI 支持现有题目筛选能力
系统 SHALL 允许用户通过 CLI 显式设置难度、标签和数量筛选，并将这些值传递给题目加载流程。

#### Scenario: 覆盖题目筛选
- **WHEN** 用户传入 `--difficulty`、`--tags` 或 `--limit`
- **THEN** 对应值覆盖配置文件中的同名筛选条件且其他配置筛选保持不变
