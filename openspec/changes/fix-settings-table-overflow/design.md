## Context

共享 `evaluation-list-table` 的最小宽度为 760px。现有首页、实验和日志列表在表格外使用 `evaluation-list-scroll`，并为外层提供键盘焦点和无障碍名称。预算页和定价页中的表格直接参与文档布局。

## Decisions

- 沿用 `evaluation-list-scroll` 和原生表格语义，在两个设置页中为每张表提供独立的、以其本地化表名命名的滚动区。
- 扩充已有设置页浏览器 fixture，让费用分项和定价历史也有数据。在 320、390、768、1024 和 1440px 检查页面和历史抽屉，验证局部横向滚动及键盘到达末列操作。
