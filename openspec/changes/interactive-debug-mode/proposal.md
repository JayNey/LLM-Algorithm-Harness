## Why

当前批量评估模式只能查看最终结果，缺少逐步调试能力。开发者需要深入理解模型在单个问题上的推理过程、手动干预测试不同参数，以及快速验证策略改进方案。交互式调试模式填补了这一空白，提供了类似传统调试器的逐步执行和检查能力。

## What Changes

- 新增 `harness debug` CLI 命令，支持单题运行模式
- 实现断点和单步执行机制，允许在策略关键步骤暂停
- 支持实时手动干预：修改 prompt、调整参数、插入自定义提示
- 提供执行轨迹可视化，显示完整推理链路
- 支持轨迹导出到 JSON 文件，便于分析和复现

## Capabilities

### New Capabilities
- `debugging/interactive-mode`: 交互式调试模式的核心能力，包括单题运行、断点控制、手动干预和轨迹可视化
