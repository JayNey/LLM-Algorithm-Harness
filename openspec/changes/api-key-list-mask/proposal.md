# Proposal: 密钥列表掩码展示

## 动机

Issue #161 的密钥管理线框图要求在列表中展示形如 `sk-*******************************` 的掩码，便于用户区分不同密钥，同时不暴露完整明文。当前实现与 `frontend/api-keys` spec 明确禁止任何掩码展示。

## 目标

- 列表每条密钥展示服务端生成的固定格式掩码（仅前缀 + 星号）。
- 不展示完整密钥、密文，也不采用「仅后四位」式泄露。
- 添加成功后仍不在页面保留用户刚输入的明文。

## 范围

- 认证库 `auth_keys` 增加 `masked_preview` 列，在创建（及可选密钥轮换）时写入。
- `GET/POST/PATCH` 密钥元数据响应包含 `masked_preview`。
- 前端解析并在 `ApiKeysPage` 渲染掩码行。
- 修改 `openspec/specs/frontend/api-keys/spec.md` 中列表展示要求。

## 非目标

- 不为历史密钥批量解密回填掩码（无 `masked_preview` 的旧记录列表不显示掩码行）。
- 不改 issue #161 其余未完成项（RBAC、头像等）。
