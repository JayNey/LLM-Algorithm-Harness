## ADDED Requirements

### Requirement: 批量导入 LeetCode 公开题到个人题库

系统 SHALL 允许已认证用户按标签、难度或两者组合筛选 LeetCode 国际站公开题，并通过后台任务将勾选的题目追加到个人题库。

#### Scenario: 筛选并预览候选题

- **WHEN** 用户按 Medium 和 Dynamic Programming 筛选，并设置单批上限
- **THEN** 系统校验筛选条件和数量上限，显示候选题的题号、标题、难度、标签和来源链接
- **AND** 预览不写入个人题库

#### Scenario: 仅导入勾选项并按用户去重

- **WHEN** 用户确认勾选的题目
- **THEN** 后台任务仅导入该用户选定的公开题，跳过当前个人题库中的重复题
- **AND** 其他用户的个人题库和共享题库不受影响
- **AND** 导入题目保留单题转换产生的需人工补全状态

#### Scenario: 部分失败并按题重试

- **WHEN** 批次中的部分题目遇到限流、超时或访问受限
- **THEN** 已成功导入的题目仍可查看，页面显示处理进度、成功数、重复跳过数、失败数和逐题失败原因
- **AND** 用户可以单独重试可恢复的失败题

#### Scenario: 继续使用已有入口

- **WHEN** 用户提交单题链接或 JSON / CSV 文件
- **THEN** 系统沿用各自的导入流程
