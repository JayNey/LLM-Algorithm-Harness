# 提议：标签体系标准化

## Problem

不同平台对同一算法概念使用不同标签，例如 `hash-table`、`hash_map` 和 `哈希表`。现有题库直接保留来源标签，导致筛选、统计和推荐无法稳定合并。

## Goal

- 用 YAML 配置维护 canonical 标签、多语言别名和推荐关键词。
- 提供不依赖模型调用的确定性标签归一化和题目标签推荐。
- 提供 `harness tags normalize --dataset ...` 预览报告，并要求用户显式指定输出路径后才写新题库。
- 支持用户 YAML 规则在内置映射上追加和覆盖标签。

## Non-goals

- 不覆盖原始题库，不自动修改用户数据。
- 不把关键词推荐当作隐藏测试或评测输入。
- 不在本 issue 引入新的在线 LLM 调用或外部标签服务。
