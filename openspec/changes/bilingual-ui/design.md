## Context

前端使用 React 18、Ant Design 6、dayjs 与 Zustand，已有 UI 偏好持久化，尚无 i18n。当前分支为 tweak/20261028/bilingual-ui，基于 comet/dashboard-real-data。

## Decisions

- 使用 i18next 与 react-i18next，资源随应用打包，不依赖运行时翻译服务。
- 支持 zh-CN 与 en-US。首次使用默认中文以保留现有体验；显式选择优先，非法或无法读取的持久化值回退中文。存储不可写时保持内存切换。
- 中文源文案用作扁平翻译 key；动态内容通过命名插值传入，React 负责转义。状态/枚举/API 参数和用户内容保持原始值，文案在呈现时翻译。
- 语言切换使用 React 订阅，不通过语言 key 重新挂载业务树，不刷新页面；语言选择器置于现有外观控制区域，认证页也提供入口。
- ConfigProvider 同步组件库语言，dayjs 同步语言，HTML lang 同步 zh-CN/en-US。日期数字遵循当前语言且保留业务精度和时区语义。
- 验证包括偏好恢复/损坏/存储异常、插值与资源对称性、全量前端单测/类型检查/构建，以及登录前后页面、路由和表单状态的浏览器检查。

## Scope

翻译应用自己提供的 UI 文案。题目内容、模型名、实验名称、代码、日志、后端任意错误细节和示例业务数据保留原文。保持既有三种外观、权限和请求生命周期。
