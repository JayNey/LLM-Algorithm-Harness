## ADDED Requirements

### Requirement: 修改密码

资料页 SHALL 提供当前密码、新密码和确认密码。密码输入 MUST 不明文展示。新密码 MUST 为 12–1024 个字符，且与确认密码一致。未通过这些规则时，页面 MUST 指出未通过的项，且 MUST NOT 发送修改请求。当前密码不正确时，页面 SHALL 保留用户名和邮箱，清空三个密码字段，并显示当前密码不正确。修改成功后 SHALL 清空三个密码字段并显示已更新。

#### Scenario: 修改密码成功

- **WHEN** 已登录用户提交正确的当前密码、符合规则的新密码和一致的确认密码
- **THEN** 页面显示已更新，并且三个密码字段为空

#### Scenario: 确认密码不一致

- **WHEN** 用户提交的确认密码与新密码不同
- **THEN** 页面指出两次密码不一致，且不发送修改请求

#### Scenario: 当前密码不正确

- **WHEN** 修改请求表示当前密码不正确
- **THEN** 页面显示当前密码不正确，用户名和邮箱保持不变，三个密码字段为空
