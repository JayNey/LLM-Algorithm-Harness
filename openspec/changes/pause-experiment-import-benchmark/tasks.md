## 1. 暂停在安全边界生效

- [x] 1.1 实验 worker 在每个组合开始前读取任务状态。读到 `paused` 后不再开始后续组合，实验记录保持 `paused`，且不再把任务写成 `completed` 或 `failed`。验证：实验暂停测试用另一条数据库连接写入 `paused`，断言未开始的组合没有执行。

- [x] 1.2 导入 worker 在每道题开始前以及写入数据集前读取任务状态。读到 `paused` 后不再处理剩余题目，也不写入数据集，导入作业保持 `paused`。验证：导入暂停测试断言数据集没有包含暂停后的题目。

- [ ] 1.3 基准 worker 在每道题开始前读取任务状态。读到 `paused` 后不再开始后续题目，运行记录保持 `paused`，且不再把任务写成 `completed` 或 `failed`。验证：基准暂停测试断言未开始的题目没有执行。
