## ADDED Requirements

### Requirement: 执行元数据快照与分析一致
系统 SHALL 在普通评估的结果和检查点保留实际执行题目的标签、难度和来源元数据；个人题覆盖同 ID 公共题时 SHALL 只使用所有者的实际执行版本，不复制个人题进公共库。所有标签筛选、成功率、失败统计及能力雷达 SHALL 优先使用快照；显式空标签 SHALL NOT 回退公共题标签。

#### Scenario: 个人题与同 ID 覆盖
- **WHEN** 用户执行纯个人题或覆盖同 ID 公共题
- **THEN** 标签筛选、统计及雷达使用实际执行题标签，其他用户不可见结果

#### Scenario: 空标签与题库改变
- **WHEN** 已快照题目标签为空或原题在结果保存后被修改
- **THEN** 分析保持快照标签与难度，空标签不被公共题覆盖

#### Scenario: 历史无快照
- **WHEN** 旧结果没有执行快照
- **THEN** 保留公共题库兼容查询且明确其非历史准确性，缺少公共题时不伪造个人标签

#### Scenario: 恢复与多策略
- **WHEN** 评估暂停恢复、Worker 中断重投递、失败或重复保存结果
- **THEN** 检查点与结果保留冻结元数据，多策略与重复写入不会重复计数或改变标签
