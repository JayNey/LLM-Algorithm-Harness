# 修复 A/B 状态轮询的失败提示与恢复

来源：issue #416（前端交付 F07，第二批前端交付修复，基线 `bf5da22c3c`）。

## Why

详情页状态轮询的 catch 无条件调度下一周期并丢弃错误对象，页面仅在初始加载失败时展示错误：
轮询期内 5xx/断网/403/404 全部静默重试，界面长期停留在旧「执行中」，既无失败提示也无就地重试入口。

## What Changes

- 抽出框架无关的 `statusPolling` 会话：终态与 403/404 停止轮询；暂时性故障保留旧快照、
  抛出可见错误并继续按固定间隔重试；dispose 中止在途请求并丢弃迟到结果。
- `useStatusPolling` 改为该会话的薄适配，公开 `error`/`fatal`/`reload`。
- 详情页：暂时性故障显示错误、「显示的状态可能已过期」标注与重试入口；403/404 停止轮询后
  不再渲染过期执行状态与启动、删除等操作入口。
- 新增 i18n 键（zh-CN/en-US）与单元测试。
