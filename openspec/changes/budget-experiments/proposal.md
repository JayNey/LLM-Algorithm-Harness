# 提议：固定预算实验与策略对比

## Problem

当前三种策略可能调用模型不同次数，直接比较通过率会混入额外算力；报告缺少固定题集、重复编号、预算消耗和价格来源。缺失 usage 或价格也不能被解释成零消耗。

## Goal

- 按模型 × 策略 × 题目 × 重复编号创建可恢复的实验单元，记录配置、题集与代码指纹。
- 为每题设置相同调用次数、Token 和耗时上限，达到限制后拒绝下一次调用。
- 区分公开样例和隐藏正式评测，输出失败类型、修复率、时间与 Token 及难度/标签分组。
- 用显式价格和来源日期分别计算输入/输出成本，未知数据保留 unknown。
- 输出 JSON、CSV 和 Markdown，并说明远端生成无法保证逐字复现。

## Non-goals

- 不新增策略搜索算法，不承诺策略一定提高通过率。
- 不承诺供应商 API 的硬 Token 上限或远端生成的位级复现。
- 不设计公网多用户实验服务。
