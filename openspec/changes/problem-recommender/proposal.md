# 提议：智能题目推荐系统

## Problem

当前题目主要依靠难度和标签手动筛选，历史评测中的失败模式没有转化成下一轮训练集。模型在动态规划、图等组合上的薄弱点需要人工查找。

## Goal

- 从历史运行和实验结果读取成功/失败记录，按难度、标签和标签组合计算失败率。
- 生成带失败率、样本数和推荐理由的弱点报告。
- 从题库筛选尚未评估的相似题目，按高失败率分组排序，并输出可直接用于后续评测的题目 JSON。
- 提供 `harness recommend --history results/ --output recommended.json` 命令和可调阈值。

## Non-goals

- 不使用机器学习或向量数据库。
- 不生成新题目，不绕过题库来源限制。
- 难度自动升降留给后续迭代。
