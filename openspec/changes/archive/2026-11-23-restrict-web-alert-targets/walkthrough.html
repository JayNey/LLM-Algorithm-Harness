统一授权规则写入和历史投递

原来

普通用户可将 HTTPS 回环或内网目标存入告警规则并交给 worker。

现在

API 与 worker 共用部署白名单，完整 URL 精确匹配；默认拒绝，历史规则也重新授权。

原因 让目的地选择权归部署者，阻断普通用户利用 worker 访问未获授权地址。白名单域名和 DNS 属于可信部署边界。
