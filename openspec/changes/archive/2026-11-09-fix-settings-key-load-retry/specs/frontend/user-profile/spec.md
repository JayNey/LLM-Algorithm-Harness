## MODIFIED Requirements

### Requirement: 查看个人资料

已登录用户 SHALL 能打开个人资料页并看到自己的用户名、邮箱和注册时间。注册时间 MUST 以本地时间展示。资料尚未返回时，页面 SHALL 显示加载状态。读取失败和成功但无资料 SHALL 有独立提示及页面内重试。迟到响应 MUST NOT 覆盖新的会话或页面状态。

#### Scenario: 打开资料页

- **WHEN** 已登录用户打开个人资料页且当前用户资料可读
- **THEN** 页面显示该用户的用户名、邮箱和对应的本地注册时间

#### Scenario: 资料请求失败

- **WHEN** 已登录用户打开个人资料页且资料请求失败
- **THEN** 页面显示读取错误和重试入口，并且不展示资料
- **AND** 接口恢复后点击重试即可在原页面查看和编辑资料

#### Scenario: 资料为空

- **WHEN** 资料读取成功但没有返回资料
- **THEN** 页面显示资料为空并提供重新读取入口
