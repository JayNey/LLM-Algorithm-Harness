## ADDED Requirements

### Requirement: 恢复 API 密钥列表读取

API 密钥管理页 SHALL 分别显示列表加载中、读取失败和成功空列表。读取失败 SHALL 提供页面内重试。密钥添加、改名或删除得到成功响应后，页面 SHALL 确认写入结果并重新读取列表。回读失败时 SHALL 同时保留写入结果并显示读取错误。重试 MUST 只发送读取请求。旧会话或已离开页面的响应 MUST NOT 改变当前列表或操作结果。

#### Scenario: 首次读取失败后恢复

- **WHEN** 密钥列表请求失败且用户在接口恢复后点击重试
- **THEN** 页面展示当前会话的密钥列表或成功空列表提示

#### Scenario: 写入成功而列表回读失败

- **WHEN** 添加、改名或删除成功，随后列表读取失败
- **THEN** 页面分别展示操作成功和列表读取失败
- **AND** 用户重试后只重新读取列表
