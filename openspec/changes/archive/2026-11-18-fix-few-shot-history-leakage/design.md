# Few-Shot 历史复用修复设计

## Context

动机与范围见 [proposal.md](proposal.md)。当前 FewShotLearningStrategy 扫描 results/**/*_results.json，直接按标签检索；ExampleProblem 丢失来源身份，提示构建不复查目标。StrategyBase.create_execution_result 只保存难度，没有完整最小题目快照。ExperimentRunner 为每个组合建立 harness，动态扫描会造成组合间示例条件漂移。阶段 3 已在 src/main.py 禁用所有 Few-Shot 增量结果复用。

## Goals / Non-Goals

目标是按 A→B 顺序闭合防泄漏与真实写出复用链路，并固定正式实验示例条件。只做可确定的身份/重复题排除；语义改写、翻译和未声明的外部别名不做自动判同。排除版本变化的同来源题，防止数据集换版本绕过过滤。无数据库迁移或联网模型依赖。

## Decisions

### 方案比较

1. 结果内嵌最小快照（本次方案）：结果独立可读，策略统一写出，无需依赖当前题库；增加可选结果字段及小型集合共享逻辑。
2. 加载历史时回查当前题库：代码局部，但历史题意可能变化或被删除，不能保证代码与题意一致，因此不采用。
3. 只手工维护固定示例文件：便于审计，但不能恢复正常结果写出→历史加载链路，因此仅作为冻结后的实验输入形式。

### A：先阻断泄漏

ExampleProblem 保留可选来源字段；同一排除函数同时用于 retrieve_similar 和 build_few_shot_prompt。来源平台/题号去除外围空白，平台大小写规范化；来源版本不参与同题区分。URL 去除查询与片段、规范化主机和尾部斜杠；协议差异不区分同一来源页。题面合并空白并 casefold 后比较，空题面不构成同题证据。检索先排除再打分及截断，阈值 0 无例外。直接提示构建也过滤，全部排除时返回基础提示。

A 的历史加载暂只补充现有字段中的来源身份，不提前扩大可加载结果范围。先运行泄漏回归，修复并验证，再提交 A。

### B：统一快照与集合

在模型中声明带版本的最小题目快照，ExecutionResult 的快照字段默认为空以兼容旧结果。StrategyBase 在创建结果时从输入 Problem 复制公开题意与来源字段；快照不使用完整 Problem 序列化，不携带任何测试列表。

共享集合模块负责校验、规范化身份、稳定排序、摘要和冻结文件。新快照优先，已存在但无效/未知版本的新快照不回退绕过校验。旧字段必须具有真实标题、描述及字符串标签列表，允许合法空标签；缺失来源可用 ID 与题面排除，记录旧格式告警。按记录隔离错误，并检查成功状态、完成标志及已有公开/隐藏失败证据。重复记录做稳定内容去重，保留来源引用。

集合摘要覆盖契约版本、规范化题目内容和代码；扫描顺序或文件时间不影响身份，来源文件与记录引用另外保存供审计。选中示例的集合身份、来源、排除原因写入结果 metadata。控制参数保留在检索层，不传入模型 SDK。

### 正式实验与兼容性

ExperimentRunner 在任何组合调度前读取候选库，针对完整实验题集检查并剔除重叠，保存冻结集合与审计信息。为各组合注入同一个冻结集合路径及预期摘要，不修改用户原始策略配置。恢复优先读取并校验已有冻结集合，不重新扫描；没有证明的旧 Few-Shot checkpoint、摘要不符或目标条件变化均在模型调用前失败。非 Few-Shot 实验不改变恢复规则。

继续沿用 Few-Shot 禁用增量复用，新增快照不把历史 Few-Shot 结果变成可增量复用结果，不扩大阶段 3 的兼容承诺。

## Risks / Trade-offs

- 无来源的语义改写无法可靠判同 → 明确支持边界，以同 ID/来源/相同题面排除和全题集实验审计覆盖可证明重叠。
- 旧数据缺题意 → 告警跳过，可能减少示例，安全退化为基础提示。
- 历史单条损坏影响全库 → 每文件及每记录单独校验，有效结果保留。
- 冻结文件被修改或丢失 → 校验摘要，停止恢复并保留历史证据。
- 预计超过 tweak 六个交付文件且新增可选字段/冻结格式 → Open 明确展示并确认同一 tweak 范围；不以文件数拆成多个 change。

## Migration Plan

先验证并提交 A，再验证并提交 B。新运行写出快照；旧正常结果通用读取不变，但缺少题意的旧记录不能用作示例。旧 Few-Shot 实验没有固定集合证明时启动新实验。后续完成 OpenSpec 一致性验证、walkthrough 及流程归档提交。回退时可保留新结果文件，旧模型忽略可选快照字段；不得在未保留 A 防泄漏的情况下单独发布 B。
