## Context

列表的取消操作从实验行读取任务 ID，详情从实验关联和进度读取活动任务。列表刷新会卸载行组件，需要在页面层保留请求错误。

## Decisions

- 复用 Ant Design Modal 的键盘与焦点行为。共享组件用同步互斥保护确认动作，提交期间禁用再次确认及关闭。
- 列表优先使用行的关联任务 ID，保留对旧响应的任务索引回退。详情优先使用最新实验响应的任务 ID，保留启动响应和旧响应的关联回退。
- 两页统一在取消尝试结束时触发原有读取流程。详情清理本地启动关联并重新读取实验、任务关联和进度，列表重新读取当前筛选页并保留取消错误。

## Risks / Trade-offs

取消可能与任务完成并发。保留 API 错误提示，并以重新读取的实验和任务状态决定显示哪些操作。
