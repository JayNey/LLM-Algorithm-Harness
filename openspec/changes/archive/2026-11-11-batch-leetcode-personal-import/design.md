## 实现

- 复用 LeetCode 导入器的列表查询和单题转换。列表查询切换到国际站当前提供的 V2，批量预览添加公开题筛选。接受最多 10 个标签与可选难度，每批最多 50 题。确认请求只传题目 slug，后台仍检查题目是否公开。
- 在现有导入任务表中保存批次及逐题结果。复用 Celery 导入任务与进度接口。每道题的写入、去重、进度和结果在同一事务中保存，暂停恢复从已保存的进度继续。
- 重试从当前用户拥有的已完成任务取出选定的可重试项，创建新批次。限流、超时和上游服务异常可重试。付费、受限、消失的题目显示具体失败原因。
- 在题库现有导入面板提供筛选、勾选和逐题重试，沿用现有任务轮询和会话隔离。保留单题链接和 JSON / CSV 文件入口。
