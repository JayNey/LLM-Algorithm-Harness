## Why

GitHub #372 记录了交互调试命令与实际策略执行脱节的问题。初始单步会退出命令循环，断点无法取消正在运行的策略，修改后的请求与实际沙箱反馈也无法通过轨迹核对。

## What Changes

- 将单步、继续、跳过和退出接到当前会话的模型与沙箱调用。
- 将受支持的参数覆盖和一次性提示干预应用到实际请求。
- 使用真实调用记录生成可查看、可导出且脱敏的轨迹，并从 CLI 入口回归验证。

## Capabilities

### New Capabilities

### Modified Capabilities

- `debugging/interactive-mode`：明确调用前后的暂停位置、干预作用域以及退出时的轨迹保存。

## Impact

改动集中在 `harness debug` 的交互控制、策略适配和轨迹记录。入口回归使用受控模型和沙箱。完成摘要的计数问题由 S15 单独跟踪。
