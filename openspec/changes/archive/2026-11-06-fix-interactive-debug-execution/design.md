## Context

调试命令循环已有暂停回调，策略也已有调试钩子，但命令的返回值只结束当前循环。部分策略直接调用模型或沙箱，需要在实际调用边界统一观测。

## Decisions

- 在调试会话内拦截该策略实例的模型和沙箱调用，结束时恢复原对象。生成断点显示已返回的模型响应，执行断点停在沙箱调用前，反馈断点显示沙箱返回值。
- 调试器区分初始提示与执行中的提示。退出使用专用控制信号穿过策略的异常处理，在 CLI 边界结束会话并保存已取得的轨迹。
- 提示编辑和注入在发送下一次模型请求时消费。采样参数保留在会话内。轮数上限在多轮策略启动时生效。
- 轨迹按模型调用编号，保存该轮实际发送的提示、响应和相关沙箱结果。追踪数据写入记录器前使用项目现有脱敏逻辑。
