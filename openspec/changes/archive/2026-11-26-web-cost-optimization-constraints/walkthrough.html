01

约束输入与请求恢复

原来

仅可选择优化目标，加载和失败时表单消失且缺少重试。

现在

可填写 USD 预算及 0–100% 最低准确率，空值保持默认；校验错误不请求，加载和失败仍可编辑，支持重试及迟到结果隔离。

原因 使 Web 能使用现有分析 API 的约束能力。

02

预算方案与真实数据校验

原来

预算分层数据被客户端丢弃，无法估算的准确率被转换为 0。

现在

展示汇总、每层推荐或不可行原因，null 准确率显示无法估算；中英文文案齐全。

原因 保留服务端事实并清楚表达约束适用范围：预算作用于分层方案，最低准确率作用于最低成本推荐及分层方案。
