## ADDED Requirements

### Requirement: 根据本人评估历史推荐下一轮题目

结果详情 SHALL 允许以当前运行作为默认历史范围，选择本人可访问的历史评估与候选题库。推荐 SHALL 复用 CLI 的失败率阈值、最小样本数及排名规则，只统计实际执行并符合 #366 统计口径的结果，并从候选中排除所选历史中已评估的题目。

#### Scenario: 预览推荐题目

- **WHEN** 用户从结果详情请求预览且所选历史和候选题库符合条件
- **THEN** 系统展示薄弱分组、失败率、样本数及每道候选题的难度和推荐理由，允许勾选题目

#### Scenario: 历史不足或无候选

- **WHEN** 历史没有足够的可统计结果、没有达到阈值的分组或没有匹配的未评估候选
- **THEN** 系统给出对应说明，未执行结果不增加失败率分母

#### Scenario: 请求不可访问的历史

- **WHEN** 所选历史含有其他用户的运行
- **THEN** 请求失败，响应不披露该运行的数据或是否存在

### Requirement: 将推荐题目用于下一轮评估

系统 SHALL 允许用户将勾选题目保存为个人题集或直接带入创建评估。个人题集 SHALL 持久保留题目 ID 引用，且只有本人可以列出或打开。从推荐进入创建评估时，创建接口 SHALL 再次校验题目访问权限，并在用户选择模型与策略并确认后按选中的题目创建任务。

#### Scenario: 保存并重新打开题集

- **WHEN** 用户保存勾选题目后刷新页面并打开该题集
- **THEN** 系统按原有引用显示题目，并允许带入创建评估

#### Scenario: 直接带选题创建

- **WHEN** 用户从预览选择部分题目并继续创建
- **THEN** 创建页只预填这些题目，用户确认后任务使用提交的题目 ID

#### Scenario: 访问失效或跨用户访问

- **WHEN** 其他用户打开个人题集，或选中的题目在创建时已无法访问
- **THEN** 系统拒绝该请求，并且不创建含无权访问题目的评估
