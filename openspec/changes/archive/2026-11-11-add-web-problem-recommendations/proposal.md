## Why

用户需要从 Web 评估结果中找出薄弱题型并选题，当前需要手动切换页面和重新筛选。把推荐和选题接入结果页后，用户可以沿用已选题目发起下一轮评估。

## What Changes

- 在结果详情预览基于所选历史和题库的推荐，并勾选题目。
- 将所选题目保存为可重新打开的个人题集，或带入创建评估页。
- 共享 CLI 推荐计算，按 #366 排除未执行结果，并在创建评估时校验题目权限。
