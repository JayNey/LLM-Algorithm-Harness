## 实现

- 从 CLI 文件适配器抽出无文件读写的分组与排序，保留 CLI 报告及题集格式。Web 使用授权历史单元的快照标签和难度，旧记录回退到可访问题目元数据。候选按现有共享与个人来源筛选，个人同 ID 覆盖共享。
- Web 推荐返回薄弱分组的失败率和样本数、题目元数据及推荐理由。空历史、无薄弱分组和无匹配候选分别反馈。
- 个人题集存储所有者、名称和题目 ID，读写均按所有者限定。打开题集时重新解析当前可访问的题目，并提示失效引用。
- 两种创建入口都将选中 ID 交给既有表单，按 ID 验证选题以支持跨页预填。推荐创建使用独立的校验入口，服务端在写入任务前再次核验题目权限。两个入口共用创建服务，随后沿用现有启动流程。
