01

每次数据访问都核验建连凭据

原来

连接只在建连时认证，注销后的旧连接仍能订阅快照、接收实时事件。

现在

处理客户端动作、发送快照及事件前重新认证原始查询参数或 Cookie 凭据；失效以 4401 关闭。每秒检查空闲连接，覆盖其他进程撤销会话和令牌自然到期。

原因 实时通道必须使用与 HTTP 相同的认证服务与共享会话状态。

02

统一关闭并释放全部订阅

原来

事件转发与连接接收各自等待，认证失效不触发退出；半初始化订阅和断连取消可能遗漏清理。

现在

发送与关闭共用锁；订阅建立后立即登记，先发送快照和确认再启动转发。连接监督接收、定期认证与关闭信号，退出时取消并等待任务，以受保护的清理过程释放全部订阅。

原因 关闭连接必须同时终止后续数据发送并回收后台资源。
