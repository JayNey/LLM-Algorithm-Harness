## 实现

- 在现有 `judge_config` 中声明 `result_argument`，使用该规则时所有测试用例提供同名的命名输入。Host 与 Docker 执行函数一次，随后通过原有结果通道写出选定参数。常规题继续采集返回值。
- `unordered_groups` 比较字符串组的多重集合。对每组排序后按组计数，保留组边界、重复元素和重复组。`unordered` 继续只忽略最外层顺序。
- 共享题目模型为 LeetCode 公开导入的已知题号和入口补足缺省规则。迁移针对缺省配置，保留显式自定义规则及现有输入、预期值和可见性。导入及加载走相同的模型，CLI 增量评估仅在有效判题配置变化时重算指纹。
- 使用固定题解验证真实 Docker 路径，并通过 Host 回归覆盖日常测试环境。
