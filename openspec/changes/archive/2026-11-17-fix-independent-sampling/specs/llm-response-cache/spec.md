# LLM 响应缓存变更

## ADDED Requirements

### Requirement: 独立采样与缓存回放
Self-Consistency 的每个候选 SHALL 独立请求供应商。独立采样 SHALL 绕过响应缓存的读取和写入。客户端 SHALL 记录采样身份及缓存命中状态，采样身份 SHALL 保留在客户端和报告侧。常规缓存调用 SHALL 继续支持按有效请求身份回放。

#### Scenario: 相同的候选文本来自独立生成
- **WHEN** 启用磁盘缓存，Self-Consistency 请求 N 个候选且预算允许全部请求
- **THEN** 系统发起 N 次逻辑采样，记录各自的采样身份，供应商可以返回相同文本

#### Scenario: 常规缓存回放
- **WHEN** 原有请求身份的有效缓存被常规生成调用命中
- **THEN** 系统记录缓存命中，按现有语义返回缓存结果并保留逻辑调用、实际付费调用和用量的计数口径

#### Scenario: 缓存启用时恢复旧候选结果
- **WHEN** 恢复启用了缓存的旧任务且候选结果的独立性无法验证
- **THEN** 系统保留历史结果，并提示既有检查点不能作为独立采样任务继续
