# Design

## 数值比较

在现有递归比较器内先处理布尔值和整数对。布尔值按类型和值比较，两个整数用整数相等运算。两个非布尔实数中含浮点值时沿用 `math.isclose` 的绝对和相对容差。列表、字典和 `unordered` 模式复用递归比较器，其中 `unordered` 保留外层顺序无关及多重集匹配语义。`exact`、`unordered_groups`、节点适配和文本比较沿各自现有分支运行。

## 版本与重评

用代码常量标记判题契约 v2，把该版本加入现有题目指纹输入。已有 CLI 增量历史指纹均会失效一次。旧报告继续显示当时的评分。README 说明 CLI 使用 `--no-incremental` 新建评估且不要恢复旧运行，Web 用同一配置创建新评估。

## 验证

先加入大整数差一的公开及隐藏阶段回归并观察修复前失败，再覆盖超过浮点精确范围的整数、嵌套结果、布尔值双向比较、浮点与其他判题模式，以及旧增量指纹的失效。
