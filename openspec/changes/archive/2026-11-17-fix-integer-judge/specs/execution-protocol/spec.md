## ADDED Requirements

### Requirement: 默认容差判题区分整数、布尔值和浮点数

共享的结构化结果比较器 MUST 对两个整数进行精确比较。涉及布尔值时 MUST 仅接受同值的两个布尔值，比较方向 MUST 不影响结果。两个非布尔实数中包含浮点值时 MUST 保留配置的绝对和相对容差。该规则 MUST 适用于公开和隐藏测试，以及列表和字典内递归比较的值。

#### Scenario: 公开与隐藏阶段拒绝相差一的大整数

- **WHEN** 期望整数为 `1000000`，候选输出整数 `1000001`
- **THEN** 默认比较方式在公开和隐藏阶段均标为错误答案

#### Scenario: 超过浮点精确表示范围的嵌套整数

- **WHEN** 列表或字典中的期望整数为 `9007199254740992`，实际整数为 `9007199254740993`
- **THEN** 比较结果为不匹配，实际整数与期望整数完全相同时为匹配

#### Scenario: 布尔值的类型边界

- **WHEN** `true` 与 `1` 或 `false` 与 `0` 比较
- **THEN** 交换比较顺序后仍不匹配，同值布尔对匹配

#### Scenario: 浮点容差和专用比较模式

- **WHEN** 配置容差的结构化浮点结果在允许误差内，或题目显式配置 exact、unordered、unordered_groups 或节点适配
- **THEN** 容差比较接受合法近似值，各专用模式应用其既有匹配规则，unordered 内部数值遵循同一类型边界
