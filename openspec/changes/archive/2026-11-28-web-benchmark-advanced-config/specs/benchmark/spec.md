## ADDED Requirements

### Requirement: 固定套件与运行筛选共同生效

基准执行 MUST 先限定到数据集中存在的套件题目，按套件顺序应用难度、标签任一匹配及题目 ID 白名单的交集，最后应用数量上限。运行传入的完整策略参数 MUST 进入实际执行配置并生效，结果题数 MUST 对应筛选后的范围。筛选不得改变套件内容或冻结规则，执行结束及异常时不得遗留临时配置或数据文件。

#### Scenario: 组合筛选与真实执行
- **WHEN** 套件包含不同难度与标签的题目且运行指定组合筛选与数量上限
- **THEN** 仅符合交集和数量上限的套件题目被执行，模型调用使用指定策略参数，结果及历史保留真实准确率与成本

#### Scenario: 空交集
- **WHEN** 套件题目存在但筛选后没有题目
- **THEN** 运行明确失败并说明没有符合条件的套件题目，不产生模型调用或伪造成功结果

#### Scenario: 旧配置兼容
- **WHEN** 运行只包含策略名称且未指定筛选
- **THEN** 使用已有默认策略参数执行套件中的可用题目，旧历史记录仍可读取
