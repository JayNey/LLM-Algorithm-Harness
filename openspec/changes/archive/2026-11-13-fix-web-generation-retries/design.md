## Context

目录探测有独立的 SDK 超时。Web 评估单元按序执行，在结果提交后更新评估已知花费。结果行包含经过脱敏的执行记录，可供历史数据查询。

## Decisions

- 创建评估时保存 `generation_timeout_seconds`，默认 60 秒，允许 1–300 秒。旧行使用同一默认值。创建入口、读取接口和恢复执行共享该值。
- Web 评估使用现有客户端的重试循环。单次请求超时取配置值和剩余时间的较小值，每次生成最多三次尝试，总时间为单次超时的三倍（最多 600 秒），包含退避，超时会取消本地 SDK 请求。账户调用额度逐次准入，重试前也检查评估与用户预算。请求失败后缺少的用量保留为未知。
- Web 结果 API 从保存的模型和沙箱错误生成固定的阶段与类型标签。对旧数据读取已脱敏的迭代记录并识别历史常见错误。前端沿用单题表、失败案例和聚类组件。
- 数据库新增可空列。迁移后旧行由读取逻辑使用默认值，创建时保存实际值。

## Risks

供应商可能已计费但未返回用量。预算判断使用已知费用，结果保留费用不完整标记。
