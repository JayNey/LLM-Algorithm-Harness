## ADDED Requirements

### Requirement: Web 模型生成超时与重试

Web 评估 SHALL 独立保存并读取生效的模型生成超时，默认 60 秒。模型目录探测 SHALL 使用其独立配置。生成 SHALL 只为可恢复的超时、限流、网络和供应商服务错误重试，并受总时间、次数、账户调用额度和已知费用预算约束。

#### Scenario: 生成超过五秒但在配置超时内成功

- **WHEN** 供应商在 Web 评估配置的生成超时内返回结果，但用时超过五秒
- **THEN** 该次生成成功，读取评估可获得保存的生成超时

#### Scenario: 可恢复错误耗尽重试

- **WHEN** 模型请求反复超时或限流
- **THEN** 一次生成最多发出三次实际尝试，每次请求使用剩余时间内的超时，重试受账户调用额度与费用预算约束

#### Scenario: 鉴权失败立即返回

- **WHEN** 模型供应商返回 401 或 403
- **THEN** 生成记录脱敏的鉴权错误并停止该次生成的尝试
