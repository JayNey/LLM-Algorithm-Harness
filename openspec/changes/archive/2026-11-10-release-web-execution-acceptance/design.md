## 验收设计

- 从候选提交构建生产镜像，使用独立 Compose 项目、卷、回环端口和临时账号。仅在供应商 HTTP 边界接入可计数替身。
- 通过同源发布入口操作实际浏览器，核对响应、Celery 消费、沙箱执行和持久化结果。注入就绪中断、WebSocket 断开以及 API 和 worker 分别重启。
- 基准按现行前端规格验收预算暂停与手动刷新。新增 Web 恢复入口由产品范围另行决定。
- 证据按已通过、失败、未执行分类，并记录候选 SHA、镜像及服务版本。
- 基准 worker 解析运行配置时补齐单一 `vanilla` 默认策略，覆盖旧队列记录及新提交。非空策略沿用保存的配置。
