## Why

CLI 增量评估目前只按首个策略名和模型名选择历史，且题目指纹遗漏会改变提示、策略路由或判题的字段。配置或题目变化后，当前报告可能混入旧条件下的结果。对应 GitHub #490。

## What Changes

- 以版本化的有效执行配置指纹判断历史是否兼容。配置不兼容或历史缺少当前版本的指纹时完整评估当前选集，并保留历史。
- 补齐题目指纹，只有配置兼容且题目指纹相同的结果才可复用。
- 记录复用来源和执行配置指纹，并验证中断恢复后报告包含全部当前题目，每题每分组只计一次。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `incremental-evaluation` 的历史兼容性、题目变更检测、来源追踪和断点恢复。

## Impact

涉及 CLI 增量评估、历史索引、运行报告元数据和离线回归。Web UI/API 的增量评估由 #475 跟踪。历史索引继续可读，兼容比较函数可供后续调用。
