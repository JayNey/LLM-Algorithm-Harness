02

只派发新增题和改题，恢复后完整重算报告

原来

标题、约束、难度、标签等字段未参与题目哈希。缩小题集后，原配置无法恢复相同增量任务。

现在

题目哈希包含提示、路由和判题输入。派发前保存原历史来源和选集。恢复校验后继续原任务，报告按完整选集生成，并将历史索引按 run ID 更新。

原因 已经评估的题和历史结果都应在恢复后只计一次。
