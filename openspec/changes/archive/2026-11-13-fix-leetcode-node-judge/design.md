## Context

导入器从 Python stub 提取无类型的入口签名。共享执行器在 Host 或 Docker 内运行 Python 后，用独立通道返回 JSON。

## Decisions

- 按公开导入来源、题号及签名选择适配。兼容 133 的旧样例键 `adjList`。用题目级配置使旧记录在加载后得到同一规则，并让增量评估识别规则变化。
- 容器和子进程内注入相应节点构造器。105 与 106 按层序序列化，保留内部空位。133 从值为 1 的根按节点编号恢复邻接表，对每行邻居排序。138 沿 next 读取节点，并将 random 引用还原为索引。
- 克隆题保留原节点强引用，验证所有输出节点与原节点互不相交。图克隆也保留原邻居列表的引用以检查是否被复用。将非法节点结果通过现有通道报告为错误答案。
- 从导入 stub 的实际类型注解识别仍不支持的节点题。说明旧记录的自动兼容和重导入方式。
