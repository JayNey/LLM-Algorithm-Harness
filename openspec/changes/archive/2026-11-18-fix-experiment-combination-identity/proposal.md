# 提案

## Why

Issue #491 指出，`org/model` 和 `org_model` 清洗后会得到同一路径，导致实验结果互相覆盖。模型或策略配置重名也会让报告无法匹配参数，当前要等实验执行结束才会报错。

## What Changes

- 同一实验内按配置顺序分配稳定的组合标识。串行和并行执行共用该标识，供目录、元数据、报告和检查点使用。
- 在发起任何模型调用前拒绝重复的模型名或策略名，并指出冲突的名称。
- 保留可区分的旧产物的报告重建能力。旧产物中若有标识或路径冲突，报告重建明确报错。旧格式检查点提示新建实验，保留已有文件。

## Impact

涉及实验配置校验、CLI 和 API 共用的实验运行器、报告生成与离线回归。新产物使用独立的组合目录命名，报告仍显示原始模型名和策略名。
