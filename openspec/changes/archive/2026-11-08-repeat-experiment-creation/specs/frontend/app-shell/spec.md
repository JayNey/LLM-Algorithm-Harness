## ADDED Requirements

### Requirement: 同一会话连续创建实验

实验创建页 SHALL 在创建操作完成且收到实验 ID 后提供开启空白草稿的操作，并保留原实验详情链接。路由切换、取消草稿和开启新草稿 MUST NOT 自动发送创建请求。创建结果未知时 SHALL 保留人工核对提示和显式重置入口，并禁止直接再次提交原草稿。

#### Scenario: 从已确认回执开启新实验

- **WHEN** 用户创建实验后从详情返回列表，再从列表进入创建页并开启新草稿
- **THEN** 同一会话显示空白表单，用户提交后进入不同实验 ID 的详情

#### Scenario: 离开创建页后收到创建响应

- **WHEN** 用户取消草稿，或在创建请求进行中离开页面并随后收到成功响应
- **THEN** 页面停留在用户所选路由，创建请求不会重复发送，再次打开创建页可以查看已确认回执

#### Scenario: 创建结果未知

- **WHEN** 创建请求超时或返回其他无法确认结果的错误，且用户离开再进入创建页
- **THEN** 页面仍提示核对实验列表并阻止直接再次提交，显式重置只开启空白草稿
