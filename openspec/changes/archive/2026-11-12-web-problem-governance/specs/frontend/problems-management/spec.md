## ADDED Requirements

### Requirement: 审核个人题库的标签和难度变更

系统 SHALL 允许用户为选中的个人题目预览标签标准化和基于本人历史评估的难度重标注，并保存经过审核的题集版本。

#### Scenario: 核对预览和依据
- **WHEN** 用户选择个人题目、历史评估和通过率阈值后请求预览
- **THEN** 系统逐题显示原标签、标准标签、附带依据的建议标签、原难度、建议难度、有效样本数和通过率
- **AND** 统计排除未执行记录，零有效样本时保留原难度并说明原因
- **AND** 预览不写入源题库

#### Scenario: 只应用批准项
- **WHEN** 用户逐项批准变更并保存
- **THEN** 系统创建保留题目 ID 的个人题集版本，仅应用获批项
- **AND** 用户刷新后可以打开新版本并使用其标签、难度和题目创建评估
- **AND** 源题库与历史评估详情继续可访问

#### Scenario: 处理无变更或过期预览
- **WHEN** 没有批准的可应用变更，或源题库在预览后已更新
- **THEN** 系统提示原因，不保存版本

#### Scenario: 限制版本与历史访问
- **WHEN** 用户在预览、保存、打开版本或创建评估时引用他人的题目、历史评估或题集版本
- **THEN** API 拒绝该请求
