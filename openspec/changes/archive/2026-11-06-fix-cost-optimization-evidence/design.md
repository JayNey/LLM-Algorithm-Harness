## Context

评估进度与结果分别持久化。基准运行持久化费用小计以及各策略的通过数和总数，当前结果 JSON 缺少定价完整性证据。

## Decisions

- 按现有模型和策略组合分组。评估分母为各运行计划题目与策略的组合数之和，旧记录缺题目 ID 时用保存的题数。按单元身份统计最新终态，忽略计划范围外的结果。部分覆盖时仅已证实的成功进入分子，完全没有结果时准确率为 null。
- 只有评估计划中的每个单元都留下可定价的终态金额，组合费用才完整。采用持久化单元金额，避免使用默认零和不完整小计。一个运行的费用不完整时，整个组合的费用保持未知。
- 基准结果在现有 JSON 中保存费用完整性，报告从有效策略计数计算准确率和通过数。未保存策略计数的旧基准仍可展示已记录的运行准确率。缺少完整性标记的历史基准费用按未知处理。
- 复用现有排名与建议入口。完整零费用保留金额 0，无法计算性价比的组合在排除区展示原因。
