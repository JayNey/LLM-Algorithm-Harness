## ADDED Requirements

### Requirement: 个人成本优化使用结果与完整费用

个人成本优化报告 SHALL 仅使用当前用户已完成的评估和基准运行。评估组合的准确率 SHALL 为持久化成功单元数除以计划的题目与策略组合数，范围为 [0,1]。无结果证据时准确率 SHALL 为未知。费用缺失、定价不完整或存在历史证据缺口的组合 SHALL 排除出已知成本排名与建议。

#### Scenario: 多策略与执行失败

- **WHEN** 一题执行两种策略且两个结果均失败，或仅有一种成功
- **THEN** 传入建议的通过数分别为 0 或 1，分母均为 2，准确率分别为 0 或 0.5

#### Scenario: 历史结果只覆盖部分计划

- **WHEN** 已完成评估缺少部分结果，或仅保留进度记录
- **THEN** 部分结果使用完整计划分母且费用未知，完全没有结果的准确率也为未知

#### Scenario: 基准费用小计和零费用

- **WHEN** 一个基准组合的任一运行缺少完整性证据，另一个组合有明确完整的零费用
- **THEN** 前者显示未知费用，后者显示零费用，两者均不参与性价比排名
