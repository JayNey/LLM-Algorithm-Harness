02

复用执行与费用隔离

原来

所有单元进入运行时，统计费用直接来自原始结果。

现在

兼容单元预填完成，仅调度剩余单元；原始度量保留，new_cost_usd 只计算新增调用。

原因 全部复用零调用，恢复与重投递保持结果和费用幂等。

查看文件和关键代码 2
修改src/tasks/evaluation.py
validate_plan → seed completed units → checkpoint replay → dispatch remaining units; reused payload source='reused'
修改api/services/evaluation_results_service.py
reuse summary + per-row source/original_cost_usd/new_cost_usd; unknown new cost is null
03

页面展示与兼容 API

原来

创建页不能选择历史复用，结果页不区分来源。

现在

增加默认关闭的复用开关、可重试预览、来源链接和本次费用；API 契约 1.9.0。

原因 用户能核对计划与新增成本，旧客户端省略新字段维持原行为。
