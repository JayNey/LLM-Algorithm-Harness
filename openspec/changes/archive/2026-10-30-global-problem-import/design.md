## 背景

动机见 `proposal.md`，行为约定见 `specs/frontend/app-shell/spec.md` 和 `specs/frontend/problems-management/spec.md`。`Shell` 管理桌面侧栏、顶部快速操作和移动导航抽屉；`ProblemsPage` 已持有带认证的导入面板，并用 URL 查询参数保存题库筛选。题库导入使用同一个会话客户端；身份变化会重建 `ProblemSessionProvider`，HTTP 客户端会拒绝旧会话的迟到响应。

## 目标与非目标

**目标：**

- 让桌面侧栏、顶部操作、移动抽屉和移动底栏使用同一条导航路径，打开现有真实导入面板。
- 在打开/关闭面板和更新题库筛选时保留正确的 URL 状态。
- 取消文件选择或提交前收起面板时不发送请求；提交期间和异步任务未终态时阻止重复提交。
- 会话切换时隔离旧响应，不让旧请求用新身份重试或污染新会话页面。

**非目标：**

- 不修改导入 API、认证协议、文件大小阈值、append/overwrite 语义或同步/异步服务行为。
- 不增加后台导入任务的取消 API 或通用任务管理页面；已经入队的任务不因收起面板而被取消。
- 不改动无关的 Mock 页面或站内通知中心。

## 备选方案

1. **URL 查询参数**：用 `/problems?import=1` 表示打开面板。支持直接打开和刷新，用户可以分享入口；代价是所有筛选更新必须保留 `import` 参数。用户已选择此方案。
2. **React Router 临时导航状态**：导航时在 state 中携带 `openImport`。URL 不变，但直接打开或刷新时不会恢复打开意图，因此不满足本 issue 的可直接进入流程体验。

## 技术方案

- 在 `Shell` 的 `onImport` 中关闭导航抽屉并导航到 `/problems?import=1`。桌面侧栏和顶部快速操作共用此回调；同一回调传给移动抽屉和底部导航中的语义化导入按钮。
- `ProblemsPage` 以查询参数驱动导入面板。页面内的导入按钮也设置 `import=1`；关闭时只移除此参数。筛选、分页等查询更新需保留当前 `import` 值，`readListQuery` 继续只读取列表参数；当前已有的 `writeListQuery` 会重建参数，应增加保留 importer intent 的封装函数。
- 保留现有 `ImportPanel` 和导入客户端。同步直导期间保持同步提交锁；异步任务入队后，只要任务状态非终态就禁用再次提交。重复点击锁必须在提交函数中同步设置，避免 React 状态重绘前重复发请求。面板收起时保持挂载并隐藏，使题库页仍在当前路由时可以保留活动 job 的进度和提交锁。
- 取消文件选择或在提交前收起面板时不调用上传接口。已排队任务不会因收起面板而取消，暂停后续处理遵循 #301 提示。
- 身份切换时，`ProblemSessionProvider` 按 owner 重建，现有 HTTP 会话标记负责拒绝旧响应；不自动用新会话重试旧提交。已经被服务器接受的请求仍归属其原认证会话。
- `MockActions` 仅由 `AppLayout` 引用，移除该入口后可删除对应文件；实现前再次全仓搜索确认没有其他引用。中英文增加移动导入短标签和必要的可访问名称。

## 风险与取舍

- **查询参数丢失**：现有 `writeListQuery` 会重建参数，可能丢掉 `import`。更新列表参数时需显式保留它，并测试筛选、分页、打开和关闭。
- **活动导入重复提交**：异步启动请求完成时 job 仍可能处于 pending。提交锁必须覆盖整个非终态，而不只覆盖 HTTP 启动请求。
- **提交后的任务不能从此面板取消**：现有 importer API 没有页面级恢复/取消控制；设计不承诺取消已入队任务，暂停状态由 #301 提供准确说明，暂停期间提交锁保持有效。
- **移动底栏空间**：第五个操作可能挤压小屏布局；用短标签和现有 flex 样式，检查 320px 宽度和键盘焦点。

## 验证策略

- 为查询参数辅助逻辑补充 RED/GREEN 测试：直接打开、刷新、保留筛选、关闭时只删除 `import`。
- 为导入提交守卫补充 RED/GREEN 测试：正在直导或 job 未终态时阻止重复提交；选择文件时取消不发请求。复用现有 auth HTTP 会话隔离回归测试，确认旧响应不能更新新 session。
- 运行相关前端测试、lint、`npx tsc -b` 和生产构建；在桌面和 320px 移动宽度检查导航、键盘可达性及真实导入面板。

## 迁移计划

不需要数据或 API 迁移。`/problems?import=1` 是新增入口；现有书签和题库筛选继续工作。
