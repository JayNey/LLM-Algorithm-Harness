## Context

Benchmark CLI 已解析 `--compare` 和 `--output`，但处理器只实现了评估分支。历史存储按 suite 名称筛选，趋势分析器已将具有准确率的记录整理为模型时间序列。

## Goals

接通已有的历史查询、趋势分析与报告生成，保留普通 benchmark 的评估和历史保存路径。

## Decisions

- 在加载评估配置和创建执行器之前分流比较模式。沿用历史的 suite 名称键，比较要求至少两个不同模型各有一个可用于绘图的准确率样本。
- 由报告生成器负责 Markdown 和图表。自定义输出目录时，图表链接以报告位置为基准。报告输出路径不得覆盖 benchmark 历史记录。
- `--output` 随 `--compare` 使用。缺历史、可用模型不足以及输出失败均通过 CLI 错误信息和非零退出码返回。
- 通过真实 CLI 入口和磁盘历史测试报告内容、图表引用、错误状态和运行记录，并运行既有普通评估测试。
