## Context

沿用 V03/V04 的生产 Nginx、FastAPI、PostgreSQL、Redis 与 Celery 编排。以 #445 标明的 `73e7050a` 对照既有规格，在本次待发布候选上取得新证据。

## Goals / Non-Goals

覆盖浏览器操作、实际 API 和持久化结果。外部模型与投递使用隔离替身，证据分别标注真实服务及替身覆盖范围。

## Decisions

- 使用独立 Compose 项目、回环入口、隔离账号和合成数据。记录候选提交和实际镜像。
- 仅对原导入作业的三次进度请求注入故障，恢复后比较作业标识、上传与创建请求数量、终态报告、列表及来源计数。
- 用真实访问 Cookie 到期触发导出边界。解析 JSON 和 CSV 内容，并用另一个账号的独有题目验证隔离。
- 由真实任务完成事件生成通知，通过实际事件处理入口重放。用独立浏览器客户端复核多页、已读和清空。
- 用可控用量跨越预算阈值，令隔离接收端分别成功和失败。核对 UI、站内预警、实际请求和已持久化的投递状态。

浏览器复验发现导出绕过共享会话，且 worker 在发送失败后删除投递占位记录。用户确认继续 tweak。导出通过共享 HTTP 客户端获取 Blob。投递结果增加状态字段，历史中的既有成功记录按成功读取，进行中的占位记录保持隐藏。失败记录在后续 worker 重新取得租约时原子替换，重试成功后更新同一历史标识，站内通知独立去重。

## Risks / Trade-offs

故障注入、接收端、模型用量和会话 TTL 等验收配置在证据中单独标注。只记录必要的状态、计数与标识摘要。
