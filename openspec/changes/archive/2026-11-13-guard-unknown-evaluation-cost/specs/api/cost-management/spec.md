## ADDED Requirements

### Requirement: Web 评估美元预算遇到未知费用时暂停

设置任务自身美元上限的 Web 评估 SHALL 在模型缺价时暂停首个单元派发；执行中出现未知费用时 SHALL 阻止同一单元的后续模型请求和重试，并暂停剩余单元派发。已记录单元的已知费用及未知标记 SHALL 在重新投递和恢复时保留，重放同一单元 MUST NOT 重复累计。

#### Scenario: 恢复后保留预算判断

- **WHEN** 有任务美元上限的 Web 评估在记录未知费用后暂停并恢复
- **THEN** 未知记录仍阻止后续派发，已知小计和未知单元数保持原值
