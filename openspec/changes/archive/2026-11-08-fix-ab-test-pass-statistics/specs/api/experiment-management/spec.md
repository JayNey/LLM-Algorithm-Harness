## ADDED Requirements

### Requirement: A/B 样本与正式统计口径

A/B 报告及结果 API SHALL 分别使用逐题的 `sample_passed` 和正式可评估题目的 `formal_passed` 计算两个变体的通过率、通过率差值的 95% 置信区间及显著性检验。没有正式可评估题目的变体其正式通过率 SHALL 为 null，缺少任一变体时该口径差值区间和检验结果 SHALL 为空或标为不可检验。无法执行的分类检验 SHALL 标为 `unavailable`，不可计算的 p 值 SHALL 为 null。详情页 SHALL 展示 API 的两组通过率。

结果 API SHALL 从 1.0 报告保存的逐题记录重算两种口径并返回 1.1 报告，原始产物保留 1.0 标识。若逐题记录不足以重算，API SHALL 返回明确的重新运行提示。

#### Scenario: 两变体均通过公开用例并失败于隐藏用例

- **WHEN** 两个变体的所有逐题结果均通过公开用例且失败于隐藏用例
- **THEN** 报告、API 与详情页均展示两个变体样本通过率 100%、正式通过率 0%

#### Scenario: 样本与正式检验分别取数

- **WHEN** 两组逐题结果的样本表现、正式表现或可评估范围不同
- **THEN** 两组通过率、差值区间与检验各由对应的逐题结果计算

#### Scenario: 纯公开题或检验退化

- **WHEN** 仅有公开题或某口径的逐题结果无法进行显著性检验
- **THEN** 样本统计仍按公开结果计算，缺失的正式通过率与差值区间返回 null，不可用的检验及其 p 值分别标为 unavailable 和 null

#### Scenario: 查询旧版报告

- **WHEN** 用户查询现有 1.0 A/B 报告
- **THEN** API 从已保存的逐题结果重算，缺少所需记录时提示重新运行
