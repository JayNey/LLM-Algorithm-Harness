# Proposal: 固定预算实验与可复现的模型、策略对比报告

## Why

不同策略调用模型的次数不同，直接比较通过率会混入额外计算量的影响；成本汇总固定使用 GPT-3.5 近似单价，与实际使用的模型不符；现有比较方法只输出少量汇总数，无法支撑可复现的模型×策略对比结论。对应上游 issue JayNey/LLM-Algorithm-Harness#15。

## What Changes

- 新增实验配置能力：支持模型 × 策略 × 题集 × 重复编号的实验组合定义（配置文件驱动）。
- 新增固定预算控制：每题支持调用数 / token / 耗时预算，达到预算后不再发起新调用；输入、输出及供应商返回的推理 token 明确计入；不支持硬 token 限制的服务明确标注。
- 新增可复现元数据：实验记录题集指纹（SHA-256 与题目 ID 列表）、有效模型参数、代码版本、预算定义与定价快照（含来源与日期）。
- 新增对比报告：同预算下对比基础单次生成与多轮策略，输出隐藏测试通过率、样例验证率、失败类型、修复率、耗时 / token，以及按难度与标签的统计；输出 JSON / CSV 与可阅读报告，重复实验给出不确定性说明。
- **MODIFIED** 未知模型定价不再按内置默认价折算成本，而是显式标记"未知"，报告不得显示 $0 误导结论。
- CLI 新增 `experiment` 子命令（配置文件驱动），现有 `run` 命令行为不变。

## Capabilities

### New Capabilities

- `experiment/budget-comparison`: 固定预算实验的配置、执行、预算控制、可复现记录与对比报告输出。

### Modified Capabilities

- `cost-estimation/custom-pricing`: 「未知模型的降级处理」需求变更为显式未知定价标记，不再使用默认定价折算成本。

## Impact

- 代码：`src/models.py`（实验配置模型）、`src/harness.py`（预算检查挂点）、`src/experiment.py`（新增，实验编排）、`src/experiment_report.py`（新增，对比报告）、`src/main.py`（CLI 子命令）、成本估算相关模块。
- 测试：新增离线固定夹具测试（正确解 / 样例过拟合 / API 失败），预算与指标手算对账；复用离线端到端回归的假模型客户端。
- 兼容性：现有 `run` 命令、结果格式与导入器不受影响；`pricing.json` 格式不变，仅未知模型行为变化。
