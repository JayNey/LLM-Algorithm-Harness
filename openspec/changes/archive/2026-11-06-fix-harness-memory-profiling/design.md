## Context

Harness 为每个策略创建一个受控沙箱。质量分析器已有空间采样接口，沙箱使用原始公开用例运行采样并检查输出。

## Goals / Non-Goals

为最终代码保存峰值字节数或不可用说明。继续使用现有沙箱的入口协议、超时、内存和导入限制。

## Decisions

- 最终质量分析接收本次策略的沙箱和题目上下文。空间分析关闭时沿用现有的质量分析路径。
- 多轮反馈继续使用静态逐轮指标进行比较。空间分析开启时，单独采样最终提交。
- 无公开用例、执行失败或后端无法采样时，沿用空间分析器的空峰值和诊断说明。

## Risks / Trade-offs

启用空间分析时，最终代码会在沙箱内执行一轮公开用例以采样。
