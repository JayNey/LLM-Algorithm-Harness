## 设计

- FilesSettings 控制上传目录、100 MiB 单文件上限、配置解析上限、每用户存储限额、过期时间与清理周期。文件物理名为 UUID，用户路径只使用已认证用户 ID；原始文件名仅作经过校验的显示名称，路径不取自用户请求。
- Multipart 读取前验证 Bearer 和用户/IP 上传限额，流式统计总请求字节。解析器限制一个文件和少量表单字段；超限关闭临时句柄并返回 413。上传处理用 UTF-8、扩展名/MIME/文本语法共同校验，拒绝二进制头、危险 YAML 标签/别名、过深结构和重复键。
- 私有文件元数据、当前题库、导入作业和任务归属写入认证 SQLite 的独立命名空间。最终保存与限额检查采用事务；追加去重按 problem_id，不复用现有 source_platform 去重口径。有效记录经 LocalJsonImporter 转换；不执行上传代码。
- 上传的配置通过 HarnessConfig/ExperimentConfig 验证，保留脱敏的规范化配置（保留 JSON/YAML 文件格式）；不把配置中的文件路径、URL 或 env 引用直接接入执行器。模板仅含无效密钥占位值，用户必须另行绑定自己的 #152 密钥。
- 直接题库上传返回分项验证报告，默认拒绝整批无效和空数据；部分有效时导入有效条目并报告无效条目。validate=false 不绕过验证。也提供对已有上传的后台导入作业与查询接口，记录每批处理进度；事务保证合并与最终作业状态一致，超时作业标记失败而非成功。
- 结果只由可信 worker 发布到已注册且未删除的用户任务。HTTP 不接收任意本机路径或声明结果所有者。当前 #148 仍为模拟器，没有真实结果时返回 404；测试真实发布结果与所有格式导出，#149 通过发布入口接入。
- JSON/CSV/Markdown/HTML 导出基于规范化结果；CSV 防公式执行，HTML 使用转义文本和附件响应，PNG 复用 ChartGenerator，ZIP 条目名由服务固定。所有下载只允许所有者，设置 no-store/nosniff/attachment，避免上传内容作为页面执行。
- 过期原始上传定时清理，派生下载在内存生成、暂存立即清理；当前题库保留在数据库。删除任务对归属记录写入 tombstone，使迟到 worker 不能重新发布；删除关联文件失败时保留隐藏元数据，后续清理重试。活跃作业引用的文件不清理，崩溃遗留暂存及改名后未登记的生成文件按保守时间回收。

## 测试与交付

真实 TestClient、临时目录和 SQLite 验证权限、大小/类型/解析限制、文件句柄、并发追加、配置脱敏、异步进度、任务删除和清理；运行全量离线套件与跨平台 CI，经独立审查修复后提交关联 PR。

- 大文件传输和导入处理采用进程级并发限额；待处理作业数量在共享数据库中限制。接收有总时长与空闲超时，小 JSON 导入提交也限制体积。日志中间件使用直接 ASGI，保证 MultipartException 可被解析器捕获并关闭磁盘句柄；CORS 覆盖提前拒绝响应。
- CSV 导出保留全部 Problem 字段，用 json-v1 单元格标记保证 None、判题参数、入口、来源与公式样式字符串无损往返；普通外部 CSV 仍支持复杂 JSON 列。
