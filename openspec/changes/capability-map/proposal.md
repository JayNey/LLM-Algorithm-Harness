# 提议：模型能力图谱

## Problem

现有实验面板主要展示通过率、Token 和成本，无法解释模型在算法设计、代码实现、调试、优化和边界处理上的相对强弱，也缺少按难度与标签的覆盖热力图。

## Goal

- 基于现有固定预算实验结果生成五个能力维度的启发式评分。
- 按模型展示能力雷达图、难度/标签统计和知识覆盖热力图。
- 在现有实验 HTML panel 中集成，不复制实验运行或报告逻辑。
- 对样本不足或没有正式隐藏测试的数据保留未知状态，并说明评分是启发式结果。

## Non-goals

- 不训练能力预测模型，不把启发式分数解释为模型内部能力的因果测量。
- 不新增题目执行流程或公网可视化服务。
