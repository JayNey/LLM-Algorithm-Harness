## ADDED Requirements

### Requirement: 最终代码的空间分析记录

Harness MUST 在启用质量与空间分析且存在最终代码时，使用当前运行的受控沙箱采集公开用例的内存峰值，并保存到最终质量指标。

#### Scenario: 公开用例采样成功

- **WHEN** 最终代码通过沙箱中的公开用例采样
- **THEN** 最终质量指标记录峰值字节数
- **AND** 多轮反馈的逐轮分析继续使用静态指标

#### Scenario: 空间分析关闭

- **WHEN** 质量分析开启且空间分析关闭
- **THEN** Harness 不因空间分析而额外执行代码

#### Scenario: 内存峰值不可用

- **WHEN** 沙箱采样失败、后端无法采样或题目没有公开用例
- **THEN** 最终空间指标的峰值保留空值并记录不可用说明
- **AND** 原有判题状态保持不变
