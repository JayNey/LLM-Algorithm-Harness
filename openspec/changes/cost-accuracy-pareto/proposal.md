# Proposal: 成本-准确率帕累托前沿

## Why

当前实验能生成成本与成功率，但缺少非支配组合和跨重复平均，用户无法直接判断不同预算下的权衡。

## What Changes

- 使用比较报告计数与已知成本，按模型、策略、配置平均可比重复。
- 计算严格支配关系、保留相同指标的前沿点，并记录排除原因。
- 生成带标签的静态散点图、JSON 与推荐报告，选择性价比组合及预算内最高成功率组合。
- 实验自动生成单实验分析；`harness pareto` 汇总多个有完整可比性快照的实验。

## Non-goals

- 不重新评测，不调用 LLM。
- 不把样例通过率与隐藏成功率混为同一指标，不承诺历史预算估算封顶。
- 不跨不同题集、预算或沙箱条件进行混合平均。
