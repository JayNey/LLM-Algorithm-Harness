# Design: 可比实验的成本-准确率前沿

新增 `src/pareto.py`，仓库已有 `src/harness.py` 为模块，沿用现有平铺分析模块布局。输入一个或多个 `comparison.json`，复用 `solved`、`denominator.total`、`formal.evaluable/solved`、`cost` 和实验元数据。

模型与策略参数的规范化摘要区分配置变体，凭据字段不参与摘要。每个变体按重复等权计算平均总成本与平均成功率并保存范围。任一重复缺价格或非法计数则排除整个变体。已知零成本合法。原始 Decimal 值用于前沿与预算比较，输出与图表才转换为普通数值。

多个实验要求完整题集 SHA/所选题目 ID、逐题预算、筛选与沙箱快照和干净工作区的代码 commit 一致，实验 ID 不重复；有效点分母必须一致。新实验元数据补充沙箱与筛选快照。历史单报告可分析，但缺快照或代码未提交时不合并多个来源。

严格支配要求成本不大于、成功率不小于且至少一项严格更好，相同指标点都保留。推荐从前沿选取：性价比按成功题数/美元，已知零成本成功点优先；预算按平均总成本筛选后选最高成功率，平率优先低成本。无可用点/无成功时给出空推荐。

实验自动写入 `comparison.json.pareto` 及 `pareto.json/PARETO.md/pareto.png`。独立 CLI 读取多个目录并写指定输出目录，输入文件保持不变。采用现有 matplotlib 依赖绘制静态图，标签编号对应外置图例，未知成本不画成零成本。

验证覆盖手算支配矩阵、重复平均、完全相同点、零值、未知价格、配置变体、不同题集/预算/分母拒绝、离线 CLI 和自动实验产物。
