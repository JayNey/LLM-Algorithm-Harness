# #444 发布候选会话与权限验收

2026-11-10。隔离项目 `harness-444-acceptance` 使用生产 Nginx、FastAPI、PostgreSQL、Redis 和 Celery，浏览器入口为 `http://127.0.0.1:18444`。候选应用源码与提交 `03cadbf1` 一致，基线为 `deab89c8`。应用与数据库配置、三名账号和业务数据均为测试专用。测试将访问令牌有效期设为 60 秒，并将应用认证限流提高至每分钟 60 次，Nginx 限流配置使用发布值。回环入口为 HTTP。

## 会话

- 未登录直接打开 `/settings/profile`，浏览器进入登录页。错密返回 401 并显示「登录失败」，正确密码返回 200 并回到个人资料。访问与刷新 Cookie 为 HttpOnly、SameSite=Lax，浏览器存储中没有访问或刷新令牌。
- 解析登录签发的 JWT，确认其有效期为 60 秒。暂时离开应用以停用前台预刷新，等待真实到期。原 Bearer 请求返回 401，浏览器返回资料页时刷新及资料查询均返回 200。访问 Cookie、刷新 Cookie 与 CSRF 均轮换，受保护查询由浏览器附带 Cookie。缺少 CSRF 或复用旧 CSRF 的写入均返回 403，资料表单带新 CSRF 保存返回 200，回读显示新邮箱。
- 通过独立 API 请求撤销浏览器正在使用的会话，撤销返回 204。浏览器刷新会话返回 401，进入登录页，重新登录返回 200 并回到原深链接。
- 通过个人资料表单改密返回 204。通过导航登出返回 204，随后浏览器资料查询、原访问令牌重放、原刷新令牌重放均返回 401。旧密码登录返回 401，新密码登录返回 200 并回到个人资料页。
- 使用同一 Chrome 用户目录关闭进程后重新启动。勾选「记住我」时仍进入个人资料，API 返回 200。未勾选时回到登录页，API 返回 401。

## 管理员入口

- 普通用户 B 的 `/users/me` 返回 `user`。直达 `/settings/system` 和 `/settings/logs` 均显示「无权访问此页面」，页面未调用受限 API。直接访问 `/system/status`、`/logs` 和 `/health/sandbox` 均返回 403。
- 管理员的 `/users/me` 返回 `admin`。系统状态与日志页均显示内容，API 返回 200。点击「检查沙箱」实际触发 `GET /health/sandbox`，返回 200，诊断状态为 `unavailable`。生产 API 镜像未安装 Docker CLI，也未挂载 Docker socket。实际评估的 worker 使用 Docker 沙箱完成了合成题。

## 跨账号资源隔离

用户 B 是属主，用户 A 是第二个普通账号。报告标识使用 SHA-256 的前 12 位。

- **评估与报告**。属主列表、详情与 Markdown 报告返回 200，真实 worker 在隔离供应商替身下通过一题。用户 A 的列表不含该评估与结果，评估及结果深链接显示找不到资源，对应 API 返回 404。进度、删除和 Markdown 报告也返回 404。报告标识为 `7b2782a48593`。
- **实验、基准与 A/B**。属主列表包含对应资源，详情返回 200。用户 A 的列表不含对应资源，三个深链接显示找不到资源，详情 API 返回 404。启动实验、修改基准套件、删除 A/B 均返回 404。实验对比、A/B 结果、基准运行和学习曲线同样返回 404。
- **个人题库**。属主上传并导入一条合成题，返回 200，个人题库接口包含该题。用户 A 的题库界面和列表 API 均未显示该题，读取导入任务、下载源文件和复用源文件导入均返回 404。
- **API 密钥**。属主列表包含自己的密钥，用户 A 的列表排除该密钥。第二账号尝试改名、删除、验证和获取可用模型均返回 404。
- **通知**。使用实际评估完成产生的通知。属主通知列表包含该记录，用户 A 的列表不含该记录，尝试标记已读返回 404。属主从通知抽屉打开对应评估，标记已读返回 200。用户 A 的通知抽屉显示空状态。
- **在途响应**。在同一浏览器文档内通过应用菜单和路由完成登出、用户 A 登录和返回密钥页。拦截并暂存用户 B 的真实密钥列表响应（200），在用户 A 的密钥可见后释放。Playwright 完成响应注入，浏览器把原请求标记为失败。页面只显示用户 A 的测试密钥。

## 全局定价

- 按已确认的规则，普通用户可查看目录与历史，页面无追加表单。带正确 CSRF 直接调用追加接口返回 403，历史仍为空。
- 管理员通过表单为含斜杠的合成模型 ID 追加零输入价，返回 201。目录和历史回读为 200，版本记录归属管理员。
- 同一浏览器切回普通用户后，目录可见，点击该模型「历史」返回 200，版本数为 1，追加表单仍不可见。

## 密钥持久化与验证层

- 在密钥页面添加和改名分别返回 201、200，回读显示新名称。通过页面验证返回 200，界面显示「已验证」。应用实际经 OpenAI SDK 调用隔离 Compose 网络内的 TLS 模型列表替身，使用合成密钥。
- 通过 API 替换密钥返回 200，验证状态重置。重启 API 后，页面和列表读回改名后的记录及「未验证」状态。隔离容器内只比较解密值的摘要，确认保存了替换后的密钥。API 响应没有返回明文。
- 在页面删除返回 204。再次重启 API 后，该密钥在页面和列表中均不存在。
- 供应商覆盖到应用、SDK、TLS 和模型列表协议层。真实外部供应商凭证、账户权限和网络连通性未验证。
