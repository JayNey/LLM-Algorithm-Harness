## 实现

- 写入 API 复用现有的服务端管理员依赖，读取继续使用登录认证。前端定价页复用当前用户角色上下文，角色确认后才向管理员显示追加表单。
- 从候选源码运行隔离的生产 Compose，使用回环 Nginx 入口和独立数据卷。两名普通用户和一名管理员均为合成账号。把访问令牌有效期设为一分钟，等待真实 JWT 到期后验证浏览器刷新。
- 私有资源先验证属主可以读取，再使用第二账号检查列表、深链接和 API。账号切换的在途请求通过浏览器延迟一条真实响应复验。密钥验证使用隔离供应商替身记录链路覆盖，实际供应商调用需授权隔离凭证。
- 真实评估验收继续使用普通账号。脚本提交评估前读取共享定价目录，核对有效单价与费用上界使用的单价。管理员在隔离环境准备匹配的价格。
