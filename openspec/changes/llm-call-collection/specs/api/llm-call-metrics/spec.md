## Purpose

为现有管理员 LLM 监控接口提供来自真实生成请求的调用次数、成功失败结果及耗时，明确重试、缓存和跨进程统计边界，避免把密钥验证、用量登记或模拟评估误报成真实模型调用。

## ADDED Requirements

### Requirement: 真实生成请求尝试采集
系统 SHALL 对支持的每次 SDK 生成请求尝试记录一次成功或失败及单调时钟耗时，重试分别计数。耗时 SHALL 排除退避等待和采集写入，成功表示 SDK 返回而非生成代码通过评测。缓存命中、模型列表与连接验证 SHALL NOT 计入。

#### Scenario: 请求成功或失败
- **WHEN** OpenAI、local、SiliconFlow 或 Anthropic 生成请求返回或抛错
- **THEN** 系统增加一次对应成功或失败计数，记录非负耗时，保留原响应或错误语义

#### Scenario: 重试与退避
- **WHEN** 第一次请求失败并退避后第二次成功
- **THEN** 共记录两次请求、一次成功一次失败，平均耗时排除退避

#### Scenario: 非生成路径
- **WHEN** 请求命中缓存、列举模型或验证连接
- **THEN** 不增加真实生成请求计数

### Requirement: 跨进程累计统计
系统 SHALL 通过现有管理员接口返回同一认证数据库中自开始采集以来已成功记录的累计调用数、成功数、失败数、成功率与平均耗时。统计 SHALL 跨连接及进程重启保留，使用一致性读取和原子更新；无样本时计数为零，成功率及平均耗时为 null。响应 SHALL 明确起点、范围及 best-effort 采集边界，并保留独立的用量登记与验证计数。

#### Scenario: worker 写入与 API 读取
- **WHEN** 独立 worker 连接完成记录，API 从相同数据库读取
- **THEN** API 返回真实计数与耗时，多连接并发更新不丢失，重开连接后保持一致

#### Scenario: 无样本与统计权限
- **WHEN** 已配置监控但没有记录的请求，管理员查询统计
- **THEN** 返回零次调用、null 成功率与平均耗时，普通用户仍不能读取全局统计

### Requirement: 采集故障隔离与隐私
系统 SHALL 保证采集初始化、计时或持久化失败不改变原请求结果或重试策略；采集 SHALL 仅持久化固定键的聚合数值，不保存提示、响应、凭证、端点或异常正文。未配置服务端认证的 CLI 请求 SHALL 正常执行。累计统计 SHALL NOT 声称覆盖采集前历史、未配置客户端或采集故障时遗漏的请求。

#### Scenario: 写入失败或计时失败
- **WHEN** 模型成功或失败，同时采集不可用
- **THEN** 原响应或异常继续返回，不产生监控引起的额外请求，统计明确为已成功记录的请求范围

#### Scenario: 敏感内容
- **WHEN** 请求或异常中含提示、响应和凭证
- **THEN** 采集存储只含固定聚合键与数值，不包含这些内容
