# 成本-准确率帕累托分析

Issue #92 使用已有实验结果寻找成本与成功率的权衡。每个模型、策略、配置变体对应一个点；同配置的重复运行等权平均，另保留最小/最大范围。分析不会发起模型调用。

完成 `harness experiment` 后，实验目录自动生成 `pareto.json`、`PARETO.md`、`pareto.png`，`comparison.json.pareto` 保存同一结构化分析，`REPORT.md` 链接详细报告。

多个可比实验可以汇总：

```bash
harness pareto --experiments results/experiments/exp-a results/experiments/exp-b \
  --output-dir results/pareto-analysis --budgets 0 1 2 5
```

`--budgets` 单位为美元，表示运行同一完整题集的预算，可为零。未指定时，按前沿点的平均成本生成预算档位。分析产物只写到输出目录，输入 `comparison.json` 不被修改。

## 数据与指标

- 默认 `--accuracy-metric overall` 使用成功题数 / 总题数，包含样例验证与隐藏评测的最终成功状态。预算耗尽的题目仍留在总题数中。
- `--accuracy-metric formal` 使用独立隐藏测试成功题数 / 有隐藏评测的题数。没有隐藏覆盖的组合不进入该分析。
- X 轴是每次完整题集运行的平均总成本；Y 轴是所选成功率。相同配置的重复运行等权平均，统计依据计数重新计算，避免使用已四舍五入的报告比率。
- 任一重复成本未知或无效时，整个配置组合被排除，并在 JSON 与报告中说明，避免只挑选成本已知的重复。已知零成本可以进入前沿；零成本的成功题数/美元比值显示为空，不伪造无穷大。
- 不同模型参数、服务商、端点或策略参数保留为不同配置变体，报告中用配置摘要标识区分。凭据不进入摘要与产物。

多个实验必须有不同实验 ID，并记录相同的题集 SHA-256、所选题目 ID、逐题预算、沙箱配置、筛选条件和代码 commit；代码快照必须来自干净工作区。缺少这些快照或使用未提交代码的历史文件仅支持单实验分析。有效组合的题集和成功率分母也必须一致，避免比较不同覆盖范围。

## 前沿和推荐

组合 A 在成本不高于 B、成功率不低于 B，且至少一个指标严格更好时支配 B。没有被支配的点是帕累托点；成本与成功率完全相同的点均保留为前沿。图中绿色菱形与连线表示前沿，灰色点表示被支配组合；编号对应模型、策略和配置图例。

“性价比之王”在前沿中按平均成功题数 / 平均成本选择；已知零成本且有成功记录的点优先。所有点均无成功时不推荐性价比之王。各预算建议选择平均成本在预算内、成功率最高的前沿点，成功率相同优先更低成本。

预算建议基于历史平均成本，并非账单封顶。样本数量与范围用于判断结果稳定程度；单次实验或少量重复不能证明未来准确率。总成本还受当前定价与缓存计费口径影响，应结合实验的定价快照检查。
