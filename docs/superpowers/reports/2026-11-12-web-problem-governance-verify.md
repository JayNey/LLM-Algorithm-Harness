## 验收场景

- **逐题预览**。Chrome 连接真实 FastAPI 和临时 SQLite，核对原标签、标准标签、建议标签的关键词与置信度、原难度、建议难度、有效样本数和通过率。失败执行计入样本，因预算未执行的单元被排除，零样本保留原难度。API 回归测试确认预览没有改写源题库。
- **应用批准项**。浏览器勾选标准化与难度重标注，保留未勾选的建议标签。刷新后从题集版本列表重开，选择版本中的一道题发起评估。创建返回 201，启动返回 202，创建请求携带版本 ID 和所选题目 ID。浏览器使用测试模型目录和内存队列。独立 worker 测试验证原题库被覆盖后仍从保存版本读取标签、难度和题干，并确认旧评估详情保持可访问。
- **无变更和过期预览**。API 拒绝空批准项及不在预览中的标签。浏览器在预览后更新源题库，保存返回 409 并提示重新预览，随后重新审核保存成功。
- **所有者权限**。API 回归覆盖他人题目、历史评估、预览令牌、版本列表和详情，以及从他人的题集版本创建评估。跨用户访问被拒绝。
