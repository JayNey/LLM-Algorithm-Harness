## 验收场景

- 预览以当前评估为默认历史范围，支持多选历史与切换候选来源。桌面 Chrome 连接真实 FastAPI 和临时 SQLite，查看薄弱标签、难度、失败率、样本数及两道题的推荐理由。
- CLI 与 Web 共用分组和排名。后端回归验证已评估题目排除，预算跳过与未完成结果不计入分母，重复引用同一次运行不会增加样本数。样本不足与无匹配候选分别返回对应空态，未达到失败率阈值时返回无薄弱分组。
- 跨用户历史查询返回 404。候选题来自共享题库和当前用户的个人题库，个人同 ID 覆盖共享。第三方个人题目在保存与推荐创建时均被拒绝。
- 桌面保存两道候选中的一道，刷新后在手机宽度从结果列表重新打开个人题集。SQLite 验证保存的是原题 ID 引用，原历史结果仍在。
- 浏览器验证两种创建路径。直接勾选和从题集打开都仅预填同一道位于普通题目列表第二页以后的题目。选择密钥、模型、策略后，创建接口分别返回 201、启动接口返回 202，两个持久化评估都只包含该题且各有异步任务关联。模型目录使用测试模型，启动使用内存队列。
- 跨用户列出和读取个人题集的测试通过。推荐创建使用独立的权限校验入口，OpenAPI v1 冻结兼容契约测试通过。
