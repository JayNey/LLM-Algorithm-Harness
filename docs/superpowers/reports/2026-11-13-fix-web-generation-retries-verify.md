## 验收结果

- 评估创建保存默认或显式的生成超时。读取接口与 worker 使用同一生效值。SQLite 迁移、旧行读取及 PostgreSQL 迁移 SQL 已验证。模型目录仍由目录服务使用其自身的请求超时。
- 可控 SDK 覆盖超过 5 秒的成功请求、取消挂起的异步请求、超时和限流重试耗尽、鉴权失败一次返回、预算收紧与用户取消拦截后续尝试。账户额度沿用逐次准入。生成默认 60 秒，最多三次尝试，总时间上限为单次配置的三倍且不超过 600 秒。
- 结果明细、失败案例和聚类读取已保存的迭代证据。接口测试覆盖历史超时、限流、鉴权、沙箱错误、前轮沙箱状态与末轮模型失败，以及脱敏内容和单元计数。Chromium 验证三个视图和生成超时回显。
- v1 契约的两个组件新增可选字段，沿用原有必填项。63 项版本、文档和通知测试通过。
