# 同一会话连续创建评估验证

结论为通过。实现提交为 `5466d2ca`，OpenSpec 任务完成 1/1，增量规格中的三个场景均有浏览器验证。

## 验收证据

- 修复前，Chrome 从第一个任务的详情返回列表并重新打开创建页，页面显示旧回执，测试等待「开始新评估」超时。修复后，点击该按钮显示空白草稿，提交第二次后进入不同的评估 ID，期间保持同一会话并使用应用内导航。
- 第一次自动启动返回 HTTP 503。用户在详情点击「启动任务」后，两个启动请求均使用 `eval-fixture-1`，重试期间创建请求始终只有一个。
- 创建返回 HTTP 503 时，用户从任务列表返回创建页仍看到核对提示。显式确认核对后可打开新草稿，创建请求计数仍为一。
