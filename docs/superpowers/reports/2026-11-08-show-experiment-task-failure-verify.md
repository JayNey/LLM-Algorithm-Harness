## 验收

- 失败轮询先返回运行中，再返回带原因的失败终态。阻塞实验详情对账响应时，标题与错误提示已更新。放行对账后采用匹配的持久化详情，刷新后显示持久化失败原因。
- 失败、完成和取消均停止轮询，各触发一次实验详情对账。完成和取消清除旧失败提示。刷新持久化终态时直接使用实验详情。
- 切换实验路由会中止旧任务请求，登出会中止旧身份下的终态对账。详情实例按实验 ID 隔离，会话 Provider 按身份隔离。任务快照还须匹配当前任务 ID、实验 ID 和任务类型。
- 排队关联、取消后同步、启动结果不确定以及旧接口关联加载和失败场景的回归通过。旧任务索引分页由客户端单元测试覆盖。共享轮询 Hook 的暂停、失败重试和卸载中止逻辑沿用原实现。
