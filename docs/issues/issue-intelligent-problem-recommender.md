# [功能] 智能题目推荐系统

## 背景与目标

当前题目选择由用户手动配置难度和标签过滤，缺少基于评估结果的智能推荐。智能题目推荐系统可根据模型弱点自动生成针对性训练集，提升评估效率和模型改进效果，增加系统智能化程度。

- 分类：智能推荐
- 建议优先级：P1（差异化功能，提升用户体验）
- 相关文档：[feature-roadmap.md](../feature-roadmap.md#4-智能题目推荐系统)

## 工作范围

### 1. 弱点分析
- 分析历史评估结果（从 `results/` 目录读取）
- 识别低准确率的标签组合（如"动态规划 + Hard"失败率高）
- 统计各算法类型的失败率分布
- 生成"弱点报告"：列出需要加强的题目类型

### 2. 题目推荐
- 根据弱点报告推荐相似题目
  - 从题库中筛选相同标签和难度的题目
  - 排除已评估过的题目（避免重复）
  - 优先推荐失败率高的类型
- 生成定制化训练数据集配置文件

### 3. 难度自适应（可选，第二阶段）
- 实时跟踪当前难度下的准确率
- 准确率 > 80% 时自动提升难度
- 准确率 < 40% 时降低难度，巩固基础
- 记录难度调整历史

## 验收标准

- [ ] 弱点分析模块读取历史结果并生成报告
- [ ] 推荐算法正确识别低准确率标签组合
- [ ] CLI 命令：`harness recommend --history results/ --output recommended.json`
- [ ] 推荐配置文件可直接用于后续评估
- [ ] 弱点报告包含：失败率排名、题目数量、推荐理由
- [ ] 文档更新：推荐系统使用指南

## 边界

- 基于规则的推荐，不涉及机器学习模型
- 仅推荐题库中已有题目，不生成新题目
- 难度自适应为可选功能，第一版可不实现

## 依赖与关联

- 前置：#15 [功能] 固定预算实验（需要历史结果数据）
- 关联：#19 [功能] 图形客户端对比结果（Web UI 可展示推荐）
- 后续扩展：基于向量相似度的题目检索（Few-Shot Learning 策略）

## 技术要点

- 弱点识别：计算 `(失败数 / 总数)` 并按标签聚合
- 推荐算法：
  1. 统计标签组合失败率
  2. 筛选失败率 > 50% 的组合
  3. 从题库匹配相同标签的题目
  4. 排除已评估题目（通过 problem_id 去重）
- 配置生成：输出标准实验配置 JSON

## 预期收益

- 实现工作量：约 7-10 天
- 用户价值：自动化训练集生成，节省人工筛选时间
- 差异化竞争点：智能化功能，超越简单过滤
- 学术价值：可应用于自适应学习研究
