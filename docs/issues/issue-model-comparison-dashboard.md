# [功能] 模型对比分析面板

## 背景与目标

当前系统一次只能评估一个模型，无法直接对比不同 LLM（GPT-4、Claude、Gemini 等）在相同题目集上的表现。用户需要多次独立运行并手动比较结果，效率低下。模型对比分析面板可显著提升项目实用价值，满足模型选型需求。

- 分类：评测对比
- 建议优先级：P1（核心功能，提升竞争力）
- 相关文档：[feature-roadmap.md](../feature-roadmap.md#2-模型对比分析面板)

## 工作范围

### 1. 配置与执行
- 支持配置文件定义多个模型（不同供应商、不同版本）
- 实验配置支持 `models: [...]` 列表
- 自动对齐评估条件：相同题目集、相同策略、相同预算
- 支持串行或并行执行（基于 TaskService）

### 2. 对比分析
- 生成横向对比报告：
  - 胜率矩阵（模型 A vs 模型 B 的胜/平/负）
  - 分难度对比（Easy/Medium/Hard 各维度）
  - 分标签对比（动态规划、贪心、图论等）
  - 成本效益分析（准确率/成本比排名）
- 统计显著性差异标注

### 3. 可视化
- HTML 报告新增对比图表：
  - 雷达图：多维度能力对比（正确性、效率、成本）
  - 散点图：成本 vs 准确率分布
  - 热力图：题目类型 × 模型性能矩阵
  - 柱状图：并排对比各指标
- 支持交互式图表（鼠标悬停显示详情）

## 验收标准

- [ ] 配置文件支持多模型定义并通过 schema 验证
- [ ] 实验模块自动运行所有模型组合
- [ ] `comparison.json` 包含模型对比的完整数据
- [ ] HTML 报告包含至少三种可视化图表
- [ ] 胜率矩阵计算正确，统计分母与分子一致
- [ ] 文档更新：实验配置说明、对比报告解读

## 边界

- 仅对比现有三种策略，不新增策略
- 可视化使用前端库（如 Chart.js、Plotly），不自建图表引擎
- 不涉及模型性能预测或推荐算法

## 依赖与关联

- 前置：#15 [功能] 固定预算实验（已完成，复用实验框架）
- 关联：#17 [功能] 本地评测 API（未来 Web UI 可复用对比数据）
- 关联：成本优化建议功能（基于对比数据推荐最优模型）

## 技术要点

- 复用 `src/experiment.py` 框架，扩展多模型维度
- 报告生成器新增 `ModelComparisonReport` 类
- 胜率计算：逐题对比，A 通过且 B 失败计 A 胜
- 可视化库选型：优先 Plotly（交互式，易集成）

## 预期收益

- 实现工作量：约 5-7 天
- 用户价值：模型选型决策依据，节省评估时间
- 项目竞争力：核心差异化功能，学术/工业都需要
- 可扩展性：未来支持自定义对比维度
