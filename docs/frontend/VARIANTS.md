# 三套已接入风格

日期：2026-10-20。Orbit、Precision、Studio 和 Frontier SVG 已由用户确认，均在同一个 React 工作台中即时切换。共享真实认证与角色守卫、同一套业务 Mock 和相同路由；没有独立 `lab.html`、比较 iframe 或原型服务器作为交付依赖。

## Orbit · 深空控制台

关注运行、观测与恢复。默认深色，也支持浅色和跟随系统。首屏用运行焦点、执行阶段、具体题数和进度环展示当前 Mock 任务；“检查当前运行”打开任务详情。完整侧栏 220px，面板圆角 10px，冷蓝背景层级支撑持续操作，没有持续扫描或闪烁效果。

## Precision · 精密实验室

关注基准、度量与比较。默认浅色，也支持深色和跟随系统。首屏将同一 HumanEval / Direct 下的两个结果并排，突出 Pass@1 和 4.2 个百分点的显示差。完整侧栏 208px，控件圆角 3px、面板 2px；下方重复比较区隐藏，使任务与关注信息保留主要位置。

## Studio · 石墨工作室

关注实验、记录与迭代。默认暖灰浅色，也支持深色和跟随系统。石墨侧栏宽 240px，在浅深模式中保留深色侧栏；首屏用 Mock 快照日期、实验主题与方法状态呈现研究记录。任务列表以规则线为主，最近任务与辅助容器采用直角。

## 六套配色与即时切换

三种风格 × 浅/深两种解析后模式形成六套配色；完整颜色值记录在 [frontend/DESIGN.md](../../frontend/DESIGN.md) 的 frontmatter，源实现为 `src/layouts/appearance.ts` 与 `src/layouts/shell.css`。`system` 是主题解析策略，不是第七套颜色。

`src/store/ui.ts` 的 `appearanceVariant` 与各风格 `themes` 管理外观状态；`main.tsx` 同步根元素，AntD ConfigProvider 使用相同状态派生主题。`localStorage['llm-harness-ui']` 保存所选风格、每种风格自己的浅/深/系统偏好和折叠偏好。切换 Precision 后选深色，再返回 Orbit，Orbit 恢复自己的偏好。浏览器存储不可用时仍可在本次运行切换。

切换不修改 URL、不刷新页面、不以风格为 key 重建路由或通知。当前仍挂载的页面筛选、输入和通知读状态保留；换路由或认证会话后的保留范围遵循各组件生命周期。主题按钮选定明确浅/深偏好，主题选择器可切回跟随系统。

## 共用响应式约束

320px 为最小验收宽度，768px 起撤下手机底部导航，1024px 起显示常驻侧栏，1024–1279px 侧栏统一 200px，1280px 起恢复完整风格侧栏与主辅列，1440px 为桌面检查宽度。CSS 另外在 360px 以下做紧凑处理，在 1536px 起增加大屏留白。不要把 1440px 检查宽度误写为独立媒体查询。

手机的首屏按各风格结构重排：Orbit 进度区下置，Precision 介绍与双模型比较纵向排列，Studio 方法记录下移；任务行改为带字段标签的卡片式内容。风格切换仅过渡颜色。减少动态偏好下，动画与过渡缩短为 0.01ms、动画迭代 1 次，以保留 AntD 浮层结束事件；自有 DesignFocus 动画仍禁用。手机风格与主题选择区保留可见的“业务与通知 · Mock”标记。

验证记录与浏览器限制见 [QA.md](QA.md)，本文不将历史原型截图作为当前实现通过的证据。
